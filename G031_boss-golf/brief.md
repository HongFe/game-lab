# G031 져주기 골프 — 기획

- 단계: 프로토 · 시작: 2026-11-27 · 기한: 2026-12-04 (7일)
- 한 문장: **상사와 접대 골프. 원 버튼 스윙으로 상사 공보다 '살짝 못하게' 쳐라 — 아슬아슬하게 질수록 승진 점수가 폭발하고, 이겨 버리면 지방 발령.**
- 유형: 하이 콘셉트 + 웃긴 샌드박스
- 참고 장르·메커닉: 원 버튼 골프(힘 막대 멈추기), '목표 바로 앞에서 멈추기(넘으면 실패)' 위험 선택, G003 폭락 러너의 '커지는 숫자를 보며 내가 멈춘다' 구조. 원작 골프 게임의 이름·그림·코스는 쓰지 않는다
- 표기: 가상 회사·가상 점수. 실제 인물·회사·브랜드·골프장 이름 없음. 상대는 **직함으로만** 부른다(대리님·과장님…)
- 풍자 수위: 갑질·폭언·성적 소재·실제 술 강요 묘사 없음. 상사는 귀엽고 둥근 캐릭터(직함 배지로 구분), 웃음 포인트는 '일부러 지는데 티가 나면 안 된다'는 상황뿐

## 재미 핵심 (폭락 러너 DNA를 어디에 옮겼나)
| 폭락 러너 | 져주기 골프 |
|---|---|
| 수익률이 오르는 걸 보며 언제 익절할지 내가 정한다 | **굴러가는 내 공이 상사 공에 다가갈수록 배수가 ×1→×2→×5→×10으로 오른다. 언제 '발 웨지'로 멈출지 내가 정한다**. 넘어가면 이겨 버림 |
| 깃발 뒤 더 버티면 ★ | 기본 홀을 다 치고 **'한 홀 더'(연장)** 를 칠수록 홀 점수가 커진다. 눈치 게이지가 차면 지방 발령 = 이번 판 0 |
| 용어가 곧 규칙(익절·물타기·세력) | 니어핀·OB·멀리건·그늘집·내기·발 웨지·눈치·지방 발령 |
| 몸이 크면 같은 몹이 다르게 작동 | 직급이 오르면 같은 '이겨 버림'·'걸림'이 다르게 처리되고, **상사마다 공 치는 버릇이 다르다** |
| FOMC·블랙스완 예고 | 돌풍·상사 OB·멀리건·그늘집·내기·갤러리를 **내 샷 전에** 예고 |

### G013 함정(힘 맞추기만 남음)을 피하는 장치 — 이 게임의 생사
1. **타이밍은 쉽게, 판단은 어렵게**: 힘 막대는 느리고(왕복 2.4초), 막대를 누르는 동안 **코스 위 착지 예상 표식이 실시간으로 움직인다**(바람 포함, 정직한 정보). 맞추는 건 어렵지 않다. 어려운 건 '어디를 노릴지'
2. **흩어짐 괄호**: 착지 표식 양옆에 흩어짐 폭(±m)이 보인다. 바람·그늘집이면 넓어진다. 상사 공에 바짝 노릴수록 배수가 크지만 괄호가 상사 공을 덮으면 이겨 버릴 수 있다 → **얼마나 여유를 둘지가 위험 선택**
3. **굴림 뒤 멈추기(발 웨지)**: 착지 뒤 공이 굴러가는 1~3초가 폭락 러너의 '익절 구간'. 배수가 오르는 걸 보며 멈출지, 더 굴릴지
4. **예고 사건이 정답을 바꾼다**: 멀리건이 예고된 홀은 여유를 크게, 상사 OB 홀은 나도 숲으로, 갤러리 홀은 발 웨지 금지 — 같은 힘 감각이 홀마다 다른 답이 된다
5. **판마다 다른 판**: 홀(핀 거리·상사 공 위치·바람·사건 순서)은 시드로 만든다. 외워서 같은 판이 되지 않는다. 같은 시드는 같은 판(검사용)
6. 자체 검사 [D]로 '완벽 타이밍 + 판단 없음' 봇이 '보통 타이밍 + 판단' 봇에게 진다는 것을 숫자로 확인한다

## 10초 안에 이해되는 핵심 행동
- **탭 = 스윙 시작, 한 번 더 탭 = 힘 확정**. 착지 예상 표식이 코스 위를 움직이니 '여기!'에서 누르면 된다
- 화면에 보이는 목표: 상사 공 바로 뒤(핀에서 조금 더 먼 쪽)에 빛나는 **금색 띠**. 띠에 멈추면 큰 배수, 상사 공을 넘어 핀에 더 가까우면 빨간 '이김'
- 공이 구를 때 아래에 **발 웨지 버튼**(2단계부터) = 지금 멈춤

## 화면 (세로 375×760 기준)
- 옆에서 본 코스. 왼쪽 티박스(나·상사 캐릭터), 오른쪽 그린과 핀. 그린 아래 바닥에 **배수 띠**가 색으로 깔린다
  - 핀까지 거리 기준 동심 띠(핀 앞뒤 양쪽). 상사 공 거리보다 가까운 곳 = 빨강(이김), 상사 공 거리 +0~1m = 금(×10), +1~3m = 주황(×5), +3~7m = 연두(×2), +7~15m = 회색(×1), 그 밖 = 옅은 빨강 빗금(티 나게 짐)
- 위 HUD(`ui-hud`): 홀 `3/4` · 점수 막대 `ui-meter`(목표 대비) · 눈치 `ui-pips`(bad) · 발 웨지 남은 수 · 바람 화살표+숫자
- 상사 머리 위: 눈 아이콘(eye 열림 = 보는 중 / eye-off = 휴대폰 봄, 3단계부터)
- 공이 날거나 구를 때 화면 가운데 **큰 배수 숫자**(`ui-big ui-num`)가 '지금 멈추면 받는 배수'를 실시간으로 보여 준다(×1 → ×2 → ×5 → ×10 → 빨간 '이김')

## 한 판의 흐름 (1판 = 1라운드, 40초~3분)
1. 메뉴에서 단계(=내 직급)를 고른다. 깬 단계 다음까지 열림
2. **홀 카드 1.2초**: 홀 번호 + 이번 홀 사건 아이콘 한 줄(예: `멀리건 · 여유 크게`). 탭하면 넘김
3. **상사 샷**(자동, 약 2.5초, 탭하면 빨리감기): 상사 공이 멈춘 자리에 상사 얼굴 깃발이 꽂히고 배수 띠가 그 뒤로 펼쳐진다
4. **내 샷**: 탭 → 힘 막대가 0→100%→0 왕복(2.4초), 착지 표식+흩어짐 괄호가 코스 위를 따라 움직임 → 탭으로 확정 → 공 비행(약 1.5초)
5. **착지 → 굴림**(그린 빠르기·경사만큼 1~3초): 배수 숫자가 오른다. 원하면 발 웨지로 멈춤
6. **판정 도장 + 상사 대사 + 점수 날아옴**(1.5초): 예) 금 도장 `종이 한 장 ×10` + 상사 "허허, 아깝네!"
7. 기본 홀을 다 치면 정산 선택 시트(`ui-sheet`): 주 버튼 **회식 가기**(utensils, 정산) / 보조 **한 홀 더**(flag, 연장). 연장 홀마다 다시 선택. 연장은 최대 6홀
8. 정산 점수 ≥ 목표 = 통과(승진 장면: 명함이 뒤집히며 직급이 바뀜) / 미달 = 다시. 눈치가 다 차면 즉시 **지방 발령**(이번 판 점수 0, 기차 타고 멀어지는 장면) → 결과 카드 → 바로 다시(0.5초 안에 누를 수 있음)

- 한 홀 약 12초. 기본 3~5홀 + 연장 0~6홀

## 숫자 쾌감
- **홀 점수 = 홀 기본점 × 띠 배수 × 총애 배수**
- 홀 기본점: 기본 홀 100 → 150 → 200 → 250 → 300. **연장 홀은 직전 ×1.5**(450 → 675 → 1,010 → 1,520 → 2,280 → 3,420) — 연장할수록 숫자가 자릿수째 커진다
- 띠 배수: 이김 0 · ×10 종이 한 장(+0~1m) · ×5 아슬아슬(+1~3m) · ×2 자연스러움(+3~7m) · ×1 무난(+7~15m) · 티 나게 짐(+15m 넘음, 일반 홀 OB) 0 + 눈치 +1
- **총애 콤보**: ×5 이상을 연달아 받으면 2연속 ×1.5, 3연속 ×2, 4연속부터 ×3. 끊기면 ×1. HUD 칩 `총애 ×2`
- ×10(종이 한 장)을 받으면 눈치 −1(상사 기분 최고)
- 굴림 중 배수 숫자가 바뀔 때마다 음이 한 칸씩 올라간다(도→미→솔→높은 도). '이김' 경계에 다가가면 숫자가 떨린다
- 점수는 가상 '점'. 결과 화면 총점은 굴러 올라가는 숫자

## 위험 선택 (판단거리 4층)
1. **조준 여유** (매 샷): 상사 공에 바짝(×10 노림, 흩어짐 괄호가 빨강에 걸침) vs 여유 있게(×2, 안전). 괄호가 화면에 보이니 '운'이 아니라 '내가 건 위험'
2. **발 웨지 타이밍** (매 굴림): 배수가 ×5일 때 멈출지, ×10 띠까지 더 굴릴지. 그린이 빠르면 금 띠를 지나 바로 빨강
3. **연장 여부** (판 끝): 지금 회식 가서 확정할지, 한 홀 더(기본점 ×1.5) 칠지. 눈치 칸이 남은 만큼만 걸 수 있다
4. **사건 대응** (예고 홀): 그늘집 한잔(배수 ×1.5, 흩어짐 2배) 받을지, 내기 홀에서 얼마나 바짝 붙일지

## 성장 사다리 — 직급이 오르면 같은 일이 다르게 작동
단계 = 내 직급. 통과하면 승진 장면(명함 뒤집힘) 후 다음 단계가 열린다.

| 단계 | 내 직급 | 눈치 칸 | 발 웨지(판마다) | 이겨 버렸을 때 | 걸렸을 때(발 웨지 중 시선) | 직급 특기 |
|---|---|---|---|---|---|---|
| 1 | 신입 | 3 | 없음 | 홀 0 · 눈치 +2 | — | 없음 |
| 2 | 사원 | 3 | 1 | 홀 0 · 눈치 +2 | — (2단계 상사는 안 봄) | 없음 |
| 3 | 대리 | 4 | 2 | 홀 0 · 눈치 +1 | 홀 0 · 눈치 +2 | 없음 |
| 4 | 과장 | 4 | 2 | 홀 0 · 눈치 +1 | 홀 0 · 눈치 +1 | **'운이 좋았습니다'** 판마다 1회: 이겨 버린 홀의 눈치 증가를 막음(홀 점수는 0) |
| 5 | 부장 | 5 | 3 | 홀 0 · 눈치 +1 | 홀 0 · 눈치 +1 | '운이 좋았습니다' 1회 + **굴림 읽기**: 착지 직후 0.5초 동안 굴림 예상 점선 |
| 6 | 사장 | 5 | 3 | 홀 0 · 눈치 +1 | 배수 반으로(홀 0 아님) · 눈치 +1 | '운이 좋았습니다' 2회 + 굴림 읽기 |

- 직급이 오를수록 '버티는 힘'이 는다. 대신 상대 상사가 더 잘 치고(공이 핀에 가까움 → 내 공도 핀 근처 좁은 곳에 떨어져야 함) 버릇이 늘어난다(아래 표)

### 상대 상사 — 같은 '상사 공'이 상사마다 다르게 작동
| 단계 | 상대 | 공 버릇(핀까지 거리) | 시선 | 특기 | 대사(이김 / ×10 / 티 남) |
|---|---|---|---|---|---|
| 1 | 대리님 | 그린 가운데, 6~12m | 없음 | 없음 | "어? 잘 치네?" / "오~ 아깝다!" / "봐주는 거야?" |
| 2 | 과장님 | 짧게 치는 편, 8~18m | 없음 | 바람에 약함(돌풍 때 공이 더 밀림) | "자네 좀 치는구먼" / "허허, 아깝네!" / "성의가 없어" |
| 3 | 차장님 | 5~15m, 가끔 OB | **있음**(2.0초 주기) | 시선: 고개 돌리기 0.6초 전 어깨 움찔 | "흠… 잘 쳤네" / "역시 날 따라오네" / "대충 치나?" |
| 4 | 부장님 | 4~12m | 있음(1.6초) | **멀리건**: 내 공이 멈춘 뒤 다시 친다 | "…자네 골프 잘 치네?" / "자네 센스 있어" / "날 놀리나?" |
| 5 | 전무님 | 3~10m, 경사 그린 | 있음(1.4초, 불규칙 — 예고 움찔은 항상) | **내기 홀** 좋아함 | "내기는 내기지" / "자네 마음에 들어" / "재미없게 치네" |
| 6 | 회장님 | 2~8m | 있음(1.2초) | 전부 + 사건 2개가 한 홀에 겹칠 수 있음 | "젊은 사람이 매섭군" / "자네 이름이 뭐랬지?" / "…" |

- 대사는 말풍선 한 줄 12자 안팎, 1.2초. 상사 얼굴 표정 3가지(웃음·뚱함·싸늘함)

## 사건 목록 (모두 내 샷 전에 예고)
예고 방식: **홀 카드**(아이콘 + 한 줄)로 먼저 보여 주고, 상사 샷 뒤 화면 위 띠 배너로 한 번 더. 내 샷 도중에 생기는 사건은 없다(시선 전환만 0.6초 전 움찔로 예고).

| 사건 | 처음 나오는 단계 | 예고 | 효과 | 바뀌는 판단 |
|---|---|---|---|---|
| 돌풍 | 2 | 홀 카드 `돌풍 · 바람 ×2` + 깃발 펄럭 | 바람 2배, 흩어짐 +50% | 괄호가 넓어져 여유를 더 둬야 함 |
| 상사 OB | 3 | 상사 공이 숲으로 → 배너 `상사 OB · 나도 숲` | 이 홀만 목표가 바뀜: **숲(OB 구역)에 떨어지면 ×5 동반 OB**, 숲 가장자리 1m 안 ×10, 그린 위 = 이김, 페어웨이 = ×1 | '일부러 숲으로' 치기. 평소 감각 반대 |
| 멀리건 | 4 | 홀 카드 `멀리건 · 여유 크게` + 상사 손에 공 2개 | 내 공이 멈춘 뒤 상사가 다시 치고 **두 번째 공이 기준**. 두 번째 공은 첫 공 기준 −4~+4m(반반) | 바짝 붙이면 멀리건 뒤 이김이 될 수 있다. 내 공이 멈춘 뒤 판정이 바뀌는 걸 지켜보는 긴장 |
| 그늘집 한잔 | 4 | 3번째 홀 뒤 시트 `그늘집 · 한잔?` 한잔 / 사양 | 한잔: 다음 2홀 배수 ×1.5, 착지 표식이 좌우로 흔들림(흩어짐 2배). 사양: 그대로(불이익 없음) | 위험을 사서 배수를 받을지 |
| 내기 홀 | 5 | 홀 카드 `내기 · 판돈 ×3` + 판돈 칩 | 이 홀 배수 ×3, 대신 이겨 버리면 눈치 +2(직급 무관). 내기 홀을 지면(×1 이상) 판돈이 다음 내기 홀로 쌓임(×3 → ×4) | 큰 판에서 얼마나 바짝 붙일지 |
| 사장님 갤러리 | 6(5단계에도 드물게) | 홀 카드 `갤러리 · 발 웨지 금지` + 카트에 구경꾼 | 이 홀 배수 ×2, 발 웨지 못 씀(모두 보고 있음) | 굴림까지 계산한 샷 한 방 |

- 한 판에 사건 홀은 기본 홀 수의 절반 이하(1단계 0개). 같은 사건이 두 홀 연속 나오지 않는다(6단계 겹침 제외)
- 예고는 카드 1장 + 배너 1줄. 동시에 안내 1개(새것이 덮음)

## 단계별 난이도 곡선 (목표 수치 — qa-tester가 실제 곡선과 대조)
| 단계 | 직급 · 상대 | 기본 홀 | 핀 거리 | 바람(m) | 흩어짐(±m) | 새 규칙 | 새 사건 | 목표 점수 | 사람 근사 봇 통과 | ★★★ | 사람 근사 봇 홀당 평균 배수 | 이겨 버림 비율 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 신입 · 대리님 | 3 | 60~90m | 0 | 0.5 | **져주기 띠**(배수 구간) | — | 800 | 85% 이상 | 25~45% | ×3.5 | 10% 이하 |
| 2 | 사원 · 과장님 | 3 | 70~100m | 0~2 | 0.8 | **발 웨지** | 돌풍 | 1,200 | 75% 이상 | 20~40% | ×3.2 | 15% 이하 |
| 3 | 대리 · 차장님 | 4 | 80~120m | 0~3 | 1.0 | **시선**(걸림) | 상사 OB | 2,000 | 70% 이상 | 20~40% | ×3.0 | 15% 이하 |

| 5 | 부장 · 전무님 | 5 | 100~140m | 1~5 | 1.4 | **경사 그린**(굴림이 옆·뒤로 휨, 그린에 화살표) | 내기 홀 | 4,500 | 70% 이상 | 20~35% | ×2.6 | 20% 이하 |

- 목표 점수는 가정값이다. proto-builder가 '생존 봇'(늘 +5m 여유, 연장 안 함)의 기본 홀 점수 중앙값 근처로 다시 맞추고 이 표를 고친 값을 자체 검사에 출력한다
- 별: ★ = 목표 이상 정산 / ★★ = 목표 × A / ★★★ = 목표 × B. A·B는 단계마다 사람 근사 봇 ★★★가 표의 범위에 들도록 따로 정한다(G003 방식). 출발값 A=1.8, B=4.0(★★ ≈ 연장 1~2홀, ★★★ ≈ 연장 3~4홀 + 콤보)
- 새 규칙이 나오는 단계 첫 홀은 사건 없음, 핀 거리 짧음(톱니 곡선: 새 것은 쉽게 배우고 그다음에 어렵게)
- 클리어 후: 6단계 통과 → **사장 취임 장면** → **무한 라운드**(연장 제한 없음, 최고 점수만 기록, 모든 상사가 홀마다 바뀜)

## 보상과 성장
- **한 판 보상**: 홀마다 판정 도장(금 `종이 한 장`·주황 `아슬아슬`…) + 상사 대사 + 날아오는 점수. 정산 때 총점 굴러 올라감 + 별 1~3 + 통과면 승진 장면(명함 뒤집힘, 새 직급 배지)
- **30초 안 첫 성공**: 1단계 1홀은 띠가 넓고(×5 띠 폭 4m) 바람 0. 첫 샷에서 대부분 ×2 이상 → 상사 "오~ 아깝다!" (약 15초)
- **다음 판 이유**:
  - 다음 직급 해금 + 결과 카드·메뉴에 '다음 단계에서 달라지는 것' 한 줄(새 상사 얼굴 + 새 규칙 아이콘 + 목표)
  - ★ 더 받기: 연장을 더 버티면 별. 결과 카드에 `★3까지 +2,140`
  - 같은 단계라도 홀·사건 순서가 판마다 달라 '이번엔 멀리건 홀을 잘 넘겨 보자'가 생긴다
- **긴 성장 (후보, 이번 프로토에서는 만들지 않음)**:
  - 명함첩: 만난 용어(니어핀·OB·멀리건·그늘집·내기·갤러리·발 웨지·눈치·지방 발령·종이 한 장) 도감
  - 골프백 강화: 별로 받은 배지로 흩어짐 −·발 웨지 +1 같은 '버티는 힘'만(G003 상점 방식, 판단은 그대로)
  - 오늘의 라운딩(날짜 고정 시드, 모두 같은 판), 직급별 최고 점수 기록, 지방 발령 지역 모음(웃음용)
- **곡선**: 위 난이도 표의 목표 점수·통과율·★★★·평균 배수·이겨 버림 비율을 qa-tester가 실제 봇 출력과 대조한다
- 과금·광고 위치는 유지 판정 뒤에 설계한다

## 판 끝 결과 카드 한 줄 (15자 안팎, 하나만)
우선순위대로 맞는 것 하나:
1. 승진: `사원 → 대리 승진`
2. 지방 발령: `지방 발령 · 이김 2번`(또는 `· 걸림 1번`)
3. 내 기록 갱신: `최고 3,120 → 4,800`
4. 종이 한 장 많음: `종이 한 장 ×10 · 3번`
5. 미달: `목표까지 −340`
- 결과 카드 구성: 별(`UI.stars`) · 총점(`ui-big ui-num`) · 위 한 줄 · 주 버튼 다시(rotate-ccw) · 보조 다음 단계(chevron-right, 통과 시)

## 첫 판 30초 안내 (글 없이 손짓)
- 1단계 1홀 첫 방문: 상사 샷이 끝나면 띠가 한 번 반짝 → `ui-hand tap` 손가락이 화면을 톡(스윙 시작) → 착지 표식이 움직이다 금·주황 띠 위에 올 때 손가락이 다시 톡. 손가락은 반복, 처음 손대면 사라짐
- 1홀 굴림 중: 배수 숫자가 오르는 걸 크게 보여 줌(설명 없음, 숫자와 음으로)
- 2단계 첫 굴림: 발 웨지 버튼 위에 손가락이 톡 + 공이 멈추는 그림(1회)
- 3단계 첫 시선: 상사 머리 위 눈 아이콘이 크게 깜빡 → 열림일 때 발 웨지 버튼이 빨갛게, 닫힘일 때 원래 색(손가락 없이 색으로)
- 새 규칙 단계 시작 카드 = 아이콘 + 한 줄(예: `발 웨지 · 굴림 멈춤`). 탭하면 닫힘
- 규칙 설명 화면·문단 없음

## 화면 글은 짧게 (사용자 규칙)
- 모든 화면 글 한 줄 15자 안팎, 아이콘 먼저, 동시에 1개
- 홀 카드 예: `홀 3 · 멀리건`, 배너 예: `상사 OB · 나도 숲`, 판정 도장 예: `종이 한 장 ×10`·`아슬아슬 ×5`·`이겨 버림`·`티 나게 짐`·`걸림!`
- HUD는 아이콘 + 숫자만(`3/4`, `1,240`, 눈치 칸, 발 웨지 수, 바람 `→ 3`)

## 공용 UI 키트 (`_shared/ui-kit/README.md`)
- `python3 tools/ui_kit.py G031`로 넣는다. `:root{--ui-accent:#3cc98a;--ui-on-accent:#06281a}` (잔디 초록). 코스는 밝은 화면이라 `<html class="ui-light">` 검토
- **시작 화면** = 대표 그림(상사와 나, 상사 공 뒤에 내 공이 '살짝' 있는 그림, `ui-hero`) + 제목 `져주기 골프` + 한 줄 `상사보다 살짝 못 쳐라` + 주 버튼 하나 `라운딩 시작`(play). 보조 최대 2개(단계 선택 `ui-levels`, 소리). 규칙 목록·면책 문구 없음(가상 회사 표기는 설정 안)
- UI 버튼·HUD·목록 머리에는 이모지 대신 아이콘: play·flag(한 홀 더)·utensils(회식 가기)·eye/eye-off(시선)·target(목표)·star·trophy·award(승진)·rotate-ccw·chevron-right·volume-2/x·pause·triangle-alert(눈치)·train-front(지방 발령 장면 보조). 필요한 추가 아이콘: `wind`(바람)·`footprints`(발 웨지)·`beer`(그늘집) — lucide-static 0.460.0에서 `icons/`에 넣고 `--all`
- 이모지는 캐릭터·보상 그림에만(`ui-em`/`ui-hero` 안). 숫자는 `ui-num`. 결과 화면 primary 하나

## 오락실 연결
- `postMessage({type:"nhc-game", game:"G031", ev, data}, "*")`. 부모 창이 없으면 보내지 않는다(단독 실행 동작)
- `ev`는 **4가지만**. 사람이 하지 않은 자동 이벤트(봇·autoplay·selftest·홀 카드 자동 진행)는 보내지 않는다
  - `input` — 사람 탭이 있을 때, 4초에 최대 1번
  - `level_start` — 라운드 시작: `{level, rank}`
  - `level_clear` — 통과 정산: `{level, score, stars, target, holes, extra, best_mult, x10, wins, caught, kicks, sec}`
  - `fail` — **한 판에 1번만**: 지방 발령 `{level, why:"exile", score_lost, hole}` / 미달 정산 `{level, why:"short", score, target}` / 판 중 나가기 `{level, why:"quit", hole}`(1홀 이상 쳤을 때만)
- 이름 등 개인정보는 data에 넣지 않는다
