# G012 집 강화하기 — 기획

- 단계: 프로토 · 시작: 2026-11-26 · 기한: 2026-12-03 (7일)
- 한 문장: **지방 원룸 월세에서 시작해 갈아타기 버튼으로 광역시 → 해운대·수성구 → 서울 → 한강뷰 펜트하우스. 역세권·학군지·호재 매물을 골라 타고, 뉴스에 웃고 운다.**
- 2026-11-26 사용자 요청 반영(v2): 실제 집값 흐름을 반영한 지역 사다리 + 학군·개발 호재/악재·역세권을 게임 규칙으로
- 유형: 엄청난 중독성 + 하이 콘셉트
- 참고 장르·메커닉: 커스텀 맵 '키우기·강화' 장르(누르면 확률로 단계 상승). 원작 이름·그림은 쓰지 않는다
- 원칙: **실제 돈·결제 없음, 확률 공개**. 주거 피해(전세사기 등)를 소재로 삼지 않는다 — 실패는 '이사' 정도로 가볍게

## 10초 안에 이해되는 핵심 행동
- **갈아타기**(강화) 버튼: 돈을 내고 확률에 걸어 한 단계 비싼 동네로
- **매물 고르기** (버튼 3개, 갈아탈 때마다 선택): 🚇 역세권 / 🎓 학군지 / 🏗️ 호재 기대
- **알바** 버튼: 탭할 때마다 돈 (막혔을 때 다시 일어서기)
- **수입**: 가만있어도 돈이 들어온다. 좋은 집일수록 많이 (2026-11-26 조정: '집 팔기'는 시뮬레이션에서 판매→재시작 무한 반복만 낳아 뺌)

## 한 판의 흐름
1. 확률이 높은 초반은 쭉쭉 오른다 → 중반부터 실패 시 한 단계 아래로 이사
2. 돈이 떨어지면: 알바를 탭하거나 월세가 쌓이길 기다린다
3. 목표: +14 펜트하우스 (그 위에 숨은 단계 🌙 하나)
4. 결과는 '최고 단계 · 시도 횟수'로 남는다

## 지역 사다리 (v2 · 시세는 2025~26년 84㎡ 안팎을 크게 어림한 게임용 숫자, 특정 단지와 무관)

- "지방이라도 비싼 곳": 해운대·수성구가 서울 외곽보다 위에 있다 — 사다리 자체가 '어? 여기가 더 비싸?' 하는 순간
- 비용 = 다음 집 시세의 10%(계약금 느낌) × 매물 보정 × 금리 뉴스. 수입 = 지금 집 시세 × 0.012 × 0.88^단계

## 매물 종류 (갈아탈 때 고르고, 그 집에 사는 동안 효과)
| 매물 | 갈아타기 비용 | 살면 |
|---|---|---|
| 🚇 역세권 | 그대로 | 수입 ×1.35 |
| 🎓 학군지 | +20% | 실패 시 하락 확률 40% → 15% (수요가 탄탄) |
| 🏗️ 호재 기대 | -15% | 뉴스 운: 개발 확정이면 큰 보너스, 사업 지연이면 수입 절반 |

## 뉴스 (25~55초마다 하나, 내 집 매물 종류와 맞을 때만 효과)
- 🚇 새 지하철역 개통 → 역세권 수입 2배(30초) / 노선 연장 무산 → 역세권 수입 -30%(25초)
- 🎓 학원가 확장 → 학군지 보너스(갈아타기 비용의 30%)
- 🏗️ 개발 계획 확정 → 호재 매물 큰 보너스(60%) / 사업 지연 → 호재 매물 수입 절반(30초)
- 모두: 금리 인상(비용 +15%) · 금리 인하(비용 -15%) · 공급 물량 증가(수입 -20%)
- 소재 원칙 유지: 전세사기·깡통전세 같은 실제 피해는 다루지 않는다

## 보상과 성장
- **한 판 보상**: 강화 순간의 두근거림(게이지 → 결과 공개), 성공 시 집이 커지며 꽃가루, 실패 시 이삿짐 트럭
- **다음 판 이유**: 다음 단계 집 모습이 궁금함, 확률표가 보여서 "한 번만 더"
- **긴 성장**: 집 도감(가 본 집), 최고 단계·최소 시도 기록
- **곡선**: 확률 95% → 33%, 실패 시 한 단계 하락(4단계부터, 학군지 15%·그 외 40%). v2 시뮬레이션(전략별 60시드, 뉴스 포함, 쉬지 않고 탭): 중앙값 역세권 5.7분·학군지 5.0분·호재 4.9분·섞어서 5.3분, 최대 약 13분 — 한 전략이 압도하지 않게 맞춤

## 손맛
- 강화 버튼 누르면 화면이 어두워지고 게이지가 차오르며 심장 소리 → 결과
- 결과 숫자 공개: "확률 45% · 나온 수 47 → 아깝다!" (아슬아슬함이 보이게)
- 성공: 하얀 번쩍 + 집 튀어오름 + 상승 효과음 / 실패: 금 가는 흔들림 + 트럭이 지나감
- 알바 탭: 동전 튀어오름 + 피치가 오르는 '딸깍'
