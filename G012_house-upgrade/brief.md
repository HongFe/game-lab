# G012 집 강화하기 — 기획

- 단계: 프로토 · 시작: 2026-11-26 · 기한: 2026-12-03 (7일)
- 한 문장: **고시원에서 시작해 강화 버튼으로 반지하 → 원룸 → 아파트 → 펜트하우스. 실패하면 이사 간다.**
- 유형: 엄청난 중독성 + 하이 콘셉트
- 참고 장르·메커닉: 커스텀 맵 '키우기·강화' 장르(누르면 확률로 단계 상승). 원작 이름·그림은 쓰지 않는다
- 원칙: **실제 돈·결제 없음, 확률 공개**. 주거 피해(전세사기 등)를 소재로 삼지 않는다 — 실패는 '이사' 정도로 가볍게

## 10초 안에 이해되는 핵심 행동
- **강화** 버튼: 돈을 내고 확률에 걸어 한 단계 위 집으로
- **알바** 버튼: 탭할 때마다 돈 (막혔을 때 다시 일어서기)
- **월세 수입**: 가만있어도 돈이 들어온다. 좋은 집일수록 많이 (2026-11-26 조정: '집 팔기'는 시뮬레이션에서 판매→재시작 무한 반복만 낳아 뺌)

## 한 판의 흐름
1. 확률이 높은 초반은 쭉쭉 오른다 → 중반부터 실패 시 한 단계 아래로 이사
2. 돈이 떨어지면: 알바를 탭하거나 월세가 쌓이길 기다린다
3. 목표: +14 펜트하우스 (그 위에 숨은 단계 🌙 하나)
4. 결과는 '최고 단계 · 시도 횟수'로 남는다

## 보상과 성장
- **한 판 보상**: 강화 순간의 두근거림(게이지 → 결과 공개), 성공 시 집이 커지며 꽃가루, 실패 시 이삿짐 트럭
- **다음 판 이유**: 다음 단계 집 모습이 궁금함, 확률표가 보여서 "한 번만 더"
- **긴 성장**: 집 도감(가 본 집), 최고 단계·최소 시도 기록
- **곡선**: 확률 95% → 33%, 비용 단계마다 1.55배, 월세 1.4배, 실패 시 40% 확률로 한 단계 하락(4단계부터). 시뮬레이션(60시드) 쉬지 않고 탭할 때 중앙값 약 5.6분, 최소 2.5분·최대 21분

## 손맛
- 강화 버튼 누르면 화면이 어두워지고 게이지가 차오르며 심장 소리 → 결과
- 결과 숫자 공개: "확률 45% · 나온 수 47 → 아깝다!" (아슬아슬함이 보이게)
- 성공: 하얀 번쩍 + 집 튀어오름 + 상승 효과음 / 실패: 금 가는 흔들림 + 트럭이 지나감
- 알바 탭: 동전 튀어오름 + 피치가 오르는 '딸깍'

## 이번 프로토에서 하지 않는 것
- 보호권·이벤트·랭킹, 집 꾸미기

## 판정
- 계속할 신호: 5명 중 3명이 시키지 않았는데 10분 이상, 또는 '한 번만 더'를 말함
- 그만둘 신호: 알바 탭이 지루하다는 반응이 다수(돈 모으기가 일처럼 느껴짐)
