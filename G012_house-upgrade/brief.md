## 갈래 지도 (시세는 2025~26년 84㎡ 안팎 어림, 게임용, 특정 단지와 무관)
| 층 | 집 (시작 시세) |
|---|---|
| 0 | 🛏️ 지방 원룸 월세 (보증금 1천) |
| 1 | 🏠 지방 원룸 전세 5천 · 🏘️ 지방 구축 빌라 8천 |
| 2 | 🏢 지방 구축 아파트 1.5억 · 🏡 서울 빌라 전세 2.5억(청약 해당지역) |
| 3 | 🏬 광역시 외곽 2.5억 · 🚌 경기 외곽 3.5억 · 🏚️ 서울 재개발구역 빌라 4억 |
| 4 | 🏙️ 광역시 신축 대단지 5억 · 🚆 2기 신도시 7억 · 🧱 서울 외곽 구축 6.5억 |
| 5 | 🌊 부산 해운대 9억 · 📖 대구 수성구 11억 · 🌳 1기 신도시 재건축 기대 13억 · 🌉 서울 마포·성동 신축 17억 |
| 6 | 📚 서울 대치동 26억 · 🏟️ 서울 송파 22억 · 🌇 서울 뉴타운 신축(재개발 입주) 20억 |
| 7 | 🌆 서울 한강변 한강뷰 펜트하우스 34억 (목표) |

대표 갈래 (각각 성격이 다름)
- **🌊 지방 상급지**: 지방 → 광역시 → 광역 신축 → 해운대·수성구 → 마포·성동/대치 → 펜트. 비규제(LTV 70%), 폭락에 덜 빠짐, 대신 오름도 완만. 해운대 → 펜트는 경매 한 방, 아니면 송파를 거쳐 감. 마포성동·뉴타운 → 펜트도 매매·경매 둘 다
- **🚆 수도권**: 지방 구축 → 경기 외곽 → 2기 신도시 → 1기 재건축 기대 → 송파·대치 → 펜트. 상승기에 크게 오르고 폭락기에 크게 빠짐, 공급 폭탄·노선 뉴스에 흔들림
- **🏚️ 재개발 몸테크**: 경기 외곽/서울 전세 → 재개발구역 빌라 → (5단계 대기) → 뉴타운 신축 → 펜트. 긴 대기 + 큰 점프. 관리처분 뒤엔 못 팜(지위양도 금지). 지연은 단계마다 최대 2번이라 **기다리면 반드시 입주**(운 완충)
- **📝 청약**: 서울 빌라 전세로 버티며 가점을 쌓고 광역 신축·신도시·마포성동·뉴타운 분양에 도전. 당첨되면 분양가(시세 72%)로 여러 층 점프, 2.5년(75초) 공사 뒤 입주. 청약은 사는 곳 근처만 열린다(지방 전세·지방 집 → 광역 신축, 서울 전세·경기 → 신도시, 서울 전세·서울 외곽 → 마포성동, 서울 전세·재개발 → 뉴타운, 서울 상급지 → 펜트 추첨 4%)
- **🔨 경매**: 대부분의 갈래에서 싸게 들어가는 우회로. 토지거래허가 예외
- **🧳 갭투자**: 전세 끼고 적은 현금으로 사 두고 2년(60초) 뒤 입주. 토허 때는 불가

## 수단별 판정 (모두 화면에 공개)
| 수단 | 판정 | 실패/변수 |
|---|---|---|
| 🏠 전세 이사 | 95%, 전세대출 80%(최대 2억) | 다른 세입자와 계약(6초 뒤 다시) |
| 🤝 매매 | 성사 확률 = 장세(회복 85 · 상승 70 · 조정 90 · 폭락 95). 토허 지역은 허가 심사 80% 먼저. **버튼 숫자는 아래 조건부 성사까지 합친 실제 확률**(회복 90 · 상승 70 · 조정 93 · 폭락 97) | 상승기: 호가 +4%(30초) / 매도자 가계약 파기 → 가계약금 배액배상 +1% / 다른 매수자. 그 외: 대출 심사 지연 12초 / 집주인 변심 / 누수 발견 → 수리비 +2% 내고 조건부 성사 |
| 🔨 경매 | 입찰가 4개(감정가 75·85·95·105%) 중 고르기. 낙찰 확률 = F(입찰) + 0.25 × (F(입찰+4%p) − F(입찰)), F = (입찰 − 경쟁 하한)/(상한 − 하한) — 차순위 포함 실제 확률. 낙찰 0%인 입찰가는 잠금. 감정가 = 15초 전 시세 → 폭락기엔 시세보다 비쌀 수 있음(⚠️) | 패찰(보증금 반환, 10초) / 낙찰 뒤 깔끔 60 · 명도 지연 25(20초) · 숨은 수리비 15(+8%, 현금이 모자라면 대출에 더함) |
| 🧳 갭투자 | 필요 현금 = 시세 × (1 − 전세가율) + 세금. 전세가율 지방 75 · 경기 68 · 서울 55% | 만기 때 보증금 돌려줄 돈이 모자라면 전세 연장(10초씩) |
| 📝 청약 | 가점(무주택 32 + 통장 17 + 부양가족 35) ≥ 커트라인이면 85%, 아니면 추첨(광역 30 · 신도시 16 · 서울 6/5% · 펜트 4%). 서울 분양은 서울 거주자만 가점제. 1주택자·타지역은 추첨 절반. **버튼 숫자 = (1차 + 예비당첨 6%) × 부적격 제외 96%** | 낙첨(12초 뒤 다음 공고) / 예비당첨 20%×30% / 부적격 4%(1년=30초 청약 금지) / 당첨 뒤 재당첨 제한 5년(150초) |
| 🏚️ 재개발 | 구역지정 → 조합설립 → 사업시행 → 관리처분 → 이주·착공 → 입주. 단계마다 지연 22%(소송이면 크게), 조합설립 전 4% 구역 해제 위기(재추진) | 입주 때 분담금(새 집 시세 32%, 60%는 대출) |

- 대출 한도 = min(LTV × 시세, 연봉 × DSR 배수). LTV 비규제 70 · 서울 40% · 생애최초 70%. DSR 40%는 금리 4%에서 연봉 약 7배. 대출 규제 강화 때 서울 고가주택 6/4/2억
- 세금: 취득세 1~3%(생애최초 200만 감면, 일시적 2주택도 1주택 세율), 양도세: 1년 미만 차익 70% · 2년 미만 60%(실제 기본값), 2년 이상 1주택 비과세(12억 넘는 부분만 10%)
- 수입 = 연봉 기준 저축 − 대출 이자 (최소 연봉의 12%는 남김 → 사건 때문에 돈이 멈추지 않음)

## 보상과 성장
- 한 판: 판정 게이지 → 결과(히트 스톱), 경매 개찰 순서 공개, 청약 추첨 공 소리, 재개발 단계 통과 알림, 입주 꽃가루
- 다음 판 이유: **루트 도감 6개**, 최단 시간. 루트 판정(`routeOf`): 재개발 입주 → 재개발 / 청약으로 5층 이상 입주 → 청약 / 경매 2번 이상(갭보다 많이) → 경매 / 갭 2번 이상 → 갭 / 그 밖 청약 입주 → 청약 / 해운대·수성 지남 → 지방 상급지 / 나머지 → 수도권. 펜트 추첨 당첨은 루트로 치지 않음
- 기다리는 동안 하는 작은 결정(쿨다운 없음, 쓸수록 비쌈, 비용·확률 공개): 🔧 리모델링(내 집, 집값의 2% × (1 + 0.5 × 횟수), 성공 90 → 75 → 60 → 45%, 시세 +4%, 한 집 4번) · 📚 자격증(연봉 8% × (1 + 0.5 × 횟수), 연봉 +5%, 8개까지) · 📝 통장 납입(무주택, 연봉 5%, 가점 +1). 앞의 한두 번만 이득이라 '모을까, 지금 쓸까'를 고르게 함
