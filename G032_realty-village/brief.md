# G032 복덕방 마을 — 기획

- 단계: 프로토 · 시작: 2026-11-27 · 기한: 2026-12-04 (7일)
- 한 문장: **가상 동네 '솔내동'에서 1턴 = 1분기. 복덕방 중개사와 흥정해 집을 사고, 방을 아늑하게 꾸며 세를 놓고, 금리·규제 뉴스를 버티며 6년 안에 순자산 사다리를 오른다. 판이 끝나면 실제 제도 한 줄을 배운다.**
- 장르: 턴제 경영 전략 시뮬 + 아늑한 생활·꾸미기 시뮬
- 유형: 끝없는 깊이 + 아름다운 그래픽
- 출처: G012 「집 갈아타기」를 잇는다(G012는 보류). 2026-11-27 사용자 요청 — 유저끼리 사고팔기, 실제 복덕방 시스템, 전략 시뮬과 실물 반영, '부동산을 배우는 게임', 턴 사이 이벤트 연출, 집 외부와 내부를 모두 보여 주는 아늑한 꾸미기 분위기

## 3. 턴 구조 (1턴 = 1분기, 한 판 24턴 = 6년, 목표 한 판 12~16분)

### 3-1. 한 턴의 순서
1. **턴 시작**: 계절 바뀜(동네 색이 봄·여름·가을·겨울로) + 예고 칩 1개
2. **할 일** — 발걸음 👣 3개(턴마다 채워짐). 보기·흥정·가구 배치는 무료, 몸을 움직이는 일만 👣를 쓴다

| 할 일 | 비용 | 내용 |
|---|---|---|
| 🏪 복덕방 들르기 | 무료 | 중개사별 매물 3~4장, 실거래 장부, 급매 알림 |
| 👣 임장 | 👣1 | 매물 내부에 들어가 숨은 특성 3칸 중 확인(4절) |
| 🤝 흥정·계약 | 무료(매물당 턴마다 2번) | 제시가 고르기 → 수락/거절. 계약은 계약서 한 장(매가·세금·수수료·대출·필요 현금) |
| 🏦 대출 | 무료 | 계약서 안 슬라이더(0 ~ 한도). 분기 이자 실시간 표시 |
| 🔧 리모델링 | 👣1 + 돈 | 도배·바닥·주방·욕실 4종. 전후 비교 연출 |
| 🪑 가구 배치 | 무료 | 가진 가구를 방에 놓기. 아늑함 ★ 계산 |
| 🔑 세 놓기 | 👣1 | 세입자 후보 2명 중 고르기(전세/월세, 성향) |
| 🔨 경매 법정 | 👣1 | 법원 경매 게시판(3턴마다 1건) 입찰 |
| 💼 부업 | 👣1 | 현금 +분기 저축의 30%(위급할 때 버티는 수단) |

3. **턴 끝 정산**(버튼 [턴 끝] 또는 👣 0개 + 할 일 없음): 줄마다 롤업
   - 월급 저축 + 월세 수입 − 대출 이자 − 관리비 → 6월이 든 분기(2분기)는 재산세, 12월 분기(4분기)는 종부세(해당 시)
   - 시세 변화: 내 집마다 ▲▼% 화살표가 튀어나오고 순자산이 마지막에 카운트업
   - 별 기준선을 넘으면 그 자리에서 ★ 팝
4. **턴 사이 이벤트 컷신**(3-2): 0~1개, 건너뛰기 가능
5. 세입자 계약 만료·재건축 단계 진행·청약 결과 같은 '정해진 일'은 컷신 대신 알림 큐(한 번에 1개)

### 3-2. 이벤트 컷신
- 화면 가운데 그림 카드(인라인 SVG 장면, 1.6초 등장 → 손 대면 바로 다음) + **한 줄**(15자 안팎) + 효과 칩(아이콘+숫자). 화면 아무 곳 탭 = 건너뛰기, 설정에서 '컷신 끄기'
- 그림은 장면 틀 6개를 돌려 쓴다(모두 직접 그림): 📺 동네 TV 뉴스(작은 TV 안 그래프 화살표) · 🏦 은행 창구(금리 숫자판이 뒤집힘) · 🏛️ 구청 게시판(공고문이 붙음) · 🚇 공사장(굴착기·노선 선) · 📮 우편함(고지서) · 🧑‍🤝‍🧑 이웃 대화(말풍선)
- **예고 → 발표 2박자**: 큰 사건(금리·규제)은 한 턴 전에 예고 칩(확률 공개) → 다음 턴 시작에 컷신으로 결과. 폭락 러너의 FOMC와 같은 리듬

## 4. 복덕방 시스템

### 4-1. NPC 공인중개사 (프로토 2명, 둘 다 둥근 콩주민·우리 디자인)
| | 꼼꼼 할머니 「솔내 복덕방」 | 번개 실장 「번개 부동산」 |
|---|---|---|
| 성격·말투 | 느긋, "천천히 봐요" | 빠름, "오늘 안 하면 나가요!" |
| 매물 수 | 턴마다 2~3장 | 턴마다 4~5장, **급매 먼저 받음**(급매 확률 ×2) |
| 정보 질 | 매물 카드 상태·향·숨은 특성 **정확**. 흥정 수락 확률을 %로 알려 줌 | 상태 ★를 한 칸 높게 말할 때가 있음(30%). 수락 확률은 표정 3단계만(😊 70%↑ · 😐 35~70 · 😠 35↓) |
| 수수료 | 정가(매매 0.5%) | 흥정 가능(0.5% → 0.3%, 한 번 깎으면 다음 턴 매물 1장 줄어듦) |
| 친밀도 | 거래할 때마다 하트 +1 → 하트 3: 숨은 매물 1장 / 하트 5: 급매 미리 알림 | 같음 |

- 2단계 후보: 신도시 분양 상담사(청약 담당), 경매 컨설턴트(권리분석 힌트, 비싼 대신 숨은 수리비 공개)
- 실제 제도 반영: 중개보수는 법정 상한 안에서 협의한다는 것만 규칙으로(요율은 게임용 0.3~0.5% 단순화, 도감에 '실제는 가격 구간별 상한')

### 4-2. 가격 세 가지
- **시세**(숨은 값): 구역 지수 × 집 유형 기본가 × 상태 × 향·층 × (1 + 아늑함 보너스 최대 3%)
- **호가**: 시세 × (1 + 매도자 욕심 0~8%, 상승기 +4%p). 카드에 크게
- **실거래**: 실거래 장부 — 같은 구역·같은 유형의 최근 3건(NPC 거래, 시세 ±3%). 카드에 호가 아래 작은 막대로 비교 → "호가가 실거래보다 6% 비싸다"가 한눈에
- **급매**: 시세 × 0.88~0.94, **이번 턴만**. 턴마다 15%(하락기 35%) 확률로 등장. 번쩍이는 빨간 배지. 급매는 숨은 특성이 나쁠 확률이 높다(40%) → 임장할지, 바로 잡을지가 위험 선택

### 4-3. 흥정
- 제시가 버튼 3개: **호가 −2% · −5% · −9%**. 각 버튼 위에 수락 확률(할머니는 %, 실장은 표정)
- 매도자 하한 = 시세 × (1 − 급함). 급함: 보통 0~4%, 급한 매도자 6~10%(카드에 '이사 급함' 말풍선 — 임장 또는 하트 3 이상일 때만 보임)
- 거절: 너무 낮게(하한보다 5% 넘게 아래) 부르면 매도자가 삐져서 호가 +1%. 같은 턴 두 번째 흥정 가능
- 상승기: 흥정 중 다른 매수자 등장(20%) → "지금 호가로 하실래요?" 한 번 더 고르기(폭락 러너의 '지금 들어갈까')
- 결과 연출: 중개사가 계약서를 내밀고 **도장 쾅**(화면 살짝 흔들림 + 인주 빨간 자국), 열쇠 짤랑

### 4-4. 정보의 불확실성(임장)
- 매물 카드엔 '상태 ★★☆ · 남향 · ?' 처럼 보이는 정보 + **물음표 칸 3개**
- 👣 임장하면 그 집 방 안으로 들어간다(내부 아이소 화면). 돋보기로 물음표 칸 3곳(벽·창·천장/바닥)을 눌러 숨은 특성이 하나씩 드러난다

| 숨은 특성 | 효과 | 확률 |
|---|---|---|
| ☀️ 햇살 맛집 | 시세 +3%, 아늑함 +1 | 20% |
| 🌳 공원 뷰 | 시세 +4% | 10% |
| 💧 누수 흔적 | 사면 수리비 시세 3% | 15% |
| 🦶 층간소음 | 세입자 만족 −1 | 15% |
| 🔌 오래된 배관 | 리모델링 비용 +50% | 15% |
| — 특별한 것 없음 | | 25% |

- 임장 안 하고 사면 계약 직후 방에 들어갈 때 드러난다(좋든 나쁘든). 확률표는 도감에 공개
- 임장 중 그 집 **원래 집주인의 가구**가 놓여 있다(생활감). 2단계에서 유저 매물이면 그 유저가 꾸민 방 그대로

## 5. 유저 간 거래 (비동기 매물 게시판) — 2단계

### 5-1. 모양
- 복덕방 안에 세 번째 탭 **'이웃 매물'**. 다른 테스터가 올린 집이 카드로 보인다(닉네임, 집 유형·구역, 아늑함 ★, 방 미리보기 썸네일, 호가)
- 내 집 → [이웃에게 내놓기] → 호가 정하기(시세 ±15% 안) → 게시판에 올라감. 내 게임에서는 그 집이 '내놓음' 상태(세는 계속 받음), 최대 4턴 유지
- 다른 유저가 사면: 판 사람은 **다음 접속 때** "○○님이 내 집을 샀어요!" 컷신 + 그 판이 진행 중이면 게임 속 돈 입금, 판이 끝났으면 도감 스티커 '첫 이웃 거래'만(돈 이월 없음 → 판 사이 인플레이션 없음)
- 산 사람은 그 유저가 꾸민 방을 그대로 받는다(가구 배치 그대로, 바꿀 수 있음) — 유저 거래만의 재미
- **세계는 각자 따로**: 모든 테스터는 같은 주(시즌)에 같은 시드의 사건 순서를 쓴다. 매물엔 올린 턴이 붙고, 사는 사람은 자기 턴 ±3 안의 매물만 본다(시세 차이가 너무 벌어지지 않게). 산 가격은 산 사람 세계의 시세로 다시 계산해 ±15% 안으로 맞춘다
- **시세 반영**: 구역 지수 = 모델 지수 × (1 + 0.2 × 유저 거래 보정). 유저 거래 보정 = 이번 시즌 그 구역 유저 거래가/모델가의 **중앙값 − 1**, 최대 ±5%. 거래 5건(서로 다른 구매자 5명) 미만이면 0

### 5-2. Supabase 표 초안 (이미 연결된 오락실 DB, `arcade/feedback.sql`과 같은 원칙: 테스터 anon은 직접 읽지 못하고 함수로만, 개인정보 없음)

  season text not null,                 -- '2026-W49' 같은 주 단위

### 5-3. 위조·어뷰징 대응
| 수법 | 막는 방법 |
|---|---|
| 자전거래(내 번호 둘로 사고팔아 시세 띄우기) | 판매자 = 구매자 금지. 같은 house_hash가 시즌 안에 두 번 넘게 오가면 `counted=false`. 시세 보정은 **평균 대신 중앙값 + 구매자 5명 이상 + ±5% 상한 + 가중 0.2** → 번호를 여러 개 만들어도 흔들 수 있는 폭이 작다 |
| 호가 조작(엄청 비싸게/싸게) | 호가는 모델 시세 ±15%(`ask_ratio`)만 DB가 받는다. 시세 보정엔 ±10% 밖 거래는 넣지 않음 |
| 숫자 위조(개발자 도구) | DB에 돈 금액이 아닌 **비율**만 저장. 판 사람이 받는 돈은 그 사람 세계에서 다시 계산. 유저 거래로 얻는 것은 게임 속 돈과 스티커뿐(현금·토큰 가치 없음 → 공격할 이유 작음) |
| 도배·스팸 | 하루 올리기 3건·사기 5건 상한(함수 안 검사). 자유 글 입력 없음(닉네임은 오락실 기존 규칙) |
| 봇 | `?autoplay`·`?selftest`에선 게시판 함수를 부르지 않음 |
| 번호 위장(남의 T번호) | 받아들인다 — 개인정보·가치가 없는 번호. 피해는 '남의 판매 알림을 미리 봄' 정도 |

## 6. 실물 반영과 '배우는' 요소

### 6-1. 가상 동네 '솔내동' — 구역 5개 (현실을 닮은 유형, 실제 지명 없음)
| 구역 | 성격 | 시세 성향 | LTV |
|---|---|---|---|
| 🚇 역세권 | 출퇴근 | 노선 뉴스에 크게 흔들림 | 규제 40% |
| 📚 학군지 | 학원가 | 꾸준히 오름, 전세 수요 높음(전세가율 65%) | 규제 40% |
| 🏗️ 신도시 블록 | 새 아파트 | 상승기 크게, 입주 폭탄에 약함 | 비규제 70% |
| 🏘️ 구도심 | 오래된 빌라·주택 | 싸고 느림, 하락기에 덜 빠짐 | 비규제 70% |
| 🚧 재개발 구역 | 낡은 빌라 | 단계 통과마다 점프, 관리처분 뒤엔 못 팜 | 비규제 70%(토허 사건 시 매매 제한 — 2단계) |

집 유형 5종(사다리): 🛏️ 원룸 오피스텔 1.6억 · 🏘️ 다세대 빌라 2.6억 · 🏢 구축 아파트 4.8억 · 🏙️ 신축 아파트 8.5억 · 🏡 마당 있는 단독 12억(구역 지수로 ±30%). 시작: 원룸 월세(보증금 1천), 현금 4천, 연봉 4천(분기 저축 약 450만)

### 6-2. 제도 = 규칙 (게임용 단순화, 수치는 실제와 다를 수 있음 — 도감에 표기)
| 제도 | 게임 규칙 | 처음 만나는 턴 |
|---|---|---|
| LTV | 대출 ≤ 시세 × LTV(규제 40 · 비규제 70 · 생애최초 70%) | T2 |
| DSR | 대출 ≤ 연봉 기준 한도(금리 4%에서 연봉 약 7배, 금리에 따라 바뀜). 둘 중 작은 쪽이 한도 | T2 |
| 취득세 | 1주택 1~3%(가격 구간), 생애최초 감면 200만, 규제 구역 2주택 8% · 3주택 12% | T1 |
| 중개보수 | 0.3~0.5%, 중개사와 협의 | T1 |
| 양도세 | 1년(4턴) 미만 차익 70% · 2년(8턴) 미만 60% · 1주택 2년 보유 비과세(12억 넘는 부분만 과세). 다주택은 기본 세율 단순화 | 첫 매도 |
| 보유세 | 2분기 재산세(시세 0.15%), 4분기 종부세(보유 합 12억 넘으면 넘는 부분 0.5%) | T2 / 해당 시 |
| 전세가율·갭 | 전세 끼고 사기 = 시세 − 전세금 + 세금만 필요. 구역별 전세가율 55~70% | T6 |
| 임대차 | 계약 2년(8턴), 갱신 1회(+2년), 갱신 때 인상 5% 상한. 전세금이 떨어지면 만기 때 차액을 돌려줘야 함 | T6 |
| 청약 가점 | 무주택 기간(최대 32) + 부양가족(35) + 통장 기간(17) = 84점 만점. 신도시 분양 공고 2회(T9·T17 전후), 가점 ≥ 커트라인 85% / 미만이면 추첨(확률 공개) | T9 |
| 재건축·재개발 단계 | 구역지정 → 조합설립 → 사업시행 → 관리처분 → 이주·착공 → 준공 입주. 단계마다 2~4턴, 지연 20%(단계마다 최대 1번 → 기다리면 반드시 입주) | T10 |
| 경매 | 감정가 기준 입찰가 3개(80·90·100%) 중 고르기. 낙찰 확률 공개. 명도 지연·숨은 수리비 확률 공개 | T12 |

- 한 레벨(턴 구간)에 새 규칙 하나: T1 매매·취득세·수수료 → T2 대출(LTV/DSR)·재산세 → T4 임장 → T6 세 놓기·전세가율 → T9 청약 → T10 재건축 → T12 경매. 처음 만날 때 📖 배지 +1, 화면엔 한 줄("LTV = 집값 대비 대출")

### 6-3. 시세는 게임 안 모델
- 외부 API·실거래 데이터 없음. 구역 지수 = 사이클 기본 흐름 × 구역 성향 + 사건 + (2단계) 유저 거래 보정. 매 턴 같은 시드면 같은 시장(검사·시즌 공유용)

### 6-4. 오늘 배운 것
- 결과 화면 맨 아래 한 줄: 이번 판에서 **가장 큰 돈이 오간 제도**(예: "양도세: 2년 안에 팔면 차익의 60%") 또는 처음 만난 용어. 누르면 도감 장으로
- 📖 용어 도감 30개(프로토), 장마다 '게임 규칙 / 실제는 이렇다(한두 줄) / 이번 판에서 나는'. 첫 장 = '게임용 단순화 · 투자 권유 아님 · 실제 수치는 바뀜'

## 7. 비주얼 방향 (외부 이미지·글꼴 없이 단일 파일)

### 7-1. 분위기
- 아늑함·둥근 모양·파스텔·생활감. 크림 바탕(#FFF6E5 계열), 민트·살구·하늘·버터 4색 + 짙은 갈색 선. 모서리 둥글게, 그림자는 부드러운 갈색 투명
- 게임 밖 UI는 공용 UI 키트(`<html class="ui-light ui-warm">`, `--ui-accent`는 살구색). 버튼·HUD 머리는 Lucide 아이콘(store·handshake·hammer·wrench·landmark·newspaper·book-open·calendar·coins·piggy-bank 등). 이모지는 집·가구·사건 그림 자리(`ui-em`)에만
- 소리: WebAudio 사인파 + 빠른 감쇠(나무 실로폰 느낌) — 정산 롤업 음계, 도장 '쿵', 열쇠 짤랑(높은 사인 2개), 계절 전환 4음. `?nojuice`로 끔

### 7-2. 그리는 방식
- **아이소메트릭 캔버스 렌더러 하나**를 동네와 방이 같이 쓴다: `iso(x,y,z)` 변환 + 기본 도형 3개(둥근 상자 = 윗면·왼면·오른면 3톤 음영, 원기둥, 공 무리) → 건물·가구·나무 모두 이 조합
- **가구 = 데이터**: `{id:'sofa', w:2, d:1, parts:[{box:[0,0,0,2,1,0.4], c:'mint'}, {box:[0,0.8,0.4,2,0.2,0.5], c:'mint'}], cozy:2, price:30}` — 그림 함수 없이 숫자만. 프로토 가구 20개(소파·침대·식탁·의자·책장·화분 3종·러그 2종·스탠드·TV장·옷장·커튼·액자·고양이 쿠션·전기난로·주방 세트·욕조·책상)
- 방 벽지·바닥은 패턴 6종(줄무늬·체크·나무결·타일·꽃점·민무늬)을 캔버스 패턴으로 생성
- 콩주민(중개사·세입자·매도자): 둥근 머리 + 몸통 캡슐 + 점 눈 + 색 다른 소품(할머니 = 뜨개 숄, 실장 = 넥타이). 걸을 때 위아래 통통
- 이벤트 컷신 그림: 인라인 SVG 장면 틀 6개(3-2)

### 7-3. 화면별 스케치 (375px 세로)
1. **시작**: 작은 아이소 동네 대표 그림(연기 나는 굴뚝, 창에 불빛) + 제목 「복덕방 마을」 + 한 줄 "사고, 꾸미고, 버텨요" + [시작] + 보조 [이어하기] [도감]
2. **동네 지도(중심 화면)**: 위 HUD 칩 4개(💰현금 · 🏦빚 · 📈순자산 → 다음 ★까지 · 📅 2년차 봄). 가운데 아이소 지도 — 구역 5개가 길로 나뉜 섬 모양, 건물 모양이 유형을 말해 준다(원룸 = 좁고 높은 상자, 빌라 = 4층 상자 + 1층 필로티, 구축 = 긴 판상형에 복도 줄, 신축 = 탑 2동 + 하늘색 유리, 단독 = 박공지붕 + 마당 나무). 매물엔 **'팝니다' 깃발**(급매는 빨간 깃발이 펄럭), 내 집엔 **살구색 지붕 + 창 불빛**, 세 놓은 집엔 창가에 세입자 그림자. 계절마다 나무 색·눈. 그 아래 예고 칩 1개. 맨 아래 dock: [복덕방] [내 집] [턴 끝] + 👣 pips 3칸
3. **복덕방 안**: 중개사 콩주민이 책상 뒤에서 인사(말풍선 한 줄), 벽에 매물 카드 3~4장이 핀으로 꽂힘. 위 탭: 할머니 / 실장 / 이웃(🔒). 카드 = 건물 그림 + 구역 아이콘 + 호가 큰 숫자 + 실거래 막대 + 물음표 칸
4. **매물 시트**(아래 시트): 호가 · 실거래 3건 막대 · 상태★ · 물음표 3칸 · 버튼 [👣 임장] [흥정](primary)
5. **임장 / 방 보기**: 건물 외관이 확대되며 벽이 열리는 전환(외관 → 아이소 방, 0.5초) → 방 안 원래 주인 가구, 물음표 3곳에 돋보기 점멸. 누르면 특성 아이콘 팝

8. **내 집(방 꾸미기)**: 아이소 방 크게(원룸 4×4칸 → 빌라 5×5 → 구축 6×5 → 신축 6×6 → 단독 6×6 + 마당 4×3). 아래 가로 서랍에 가구, 끌어다 칸에 놓기(격자 스냅), 두 번 탭 = 회전, 밖으로 끌면 서랍으로. 위에 아늑함 ★5칸. [🔧 리모델링] → 벽지·바닥 고르면 **전후 와이프**(손가락으로 좌우 끌어 비교). [🔑 세 놓기]. 집이 여러 채면 위쪽 집 칩으로 전환(방 전환은 옆으로 미끄러짐)
9. **턴 끝 정산**: 장부 카드에 줄이 하나씩 내려오며 숫자 롤업 → 집마다 ▲▼% → 순자산 큰 숫자 카운트업 → ★ 넘으면 팝
10. **이벤트 컷신**: 어두운 막 위 그림 카드 + 한 줄 + 효과 칩 + 구석에 '건너뛰기'
11. **결과**: 큰 순자산 숫자 + 별 3 + 이번 판 이사 경로(집 아이콘 줄) + **오늘 배운 것** 한 줄 + [다시](primary) [도감]. 캡션 한 줄 '게임용 단순화 · 투자 권유 아님'
