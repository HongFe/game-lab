# G003 폭락 러너 — 기획

- 단계: 프로토 · 시작: 2026-11-26 · 기한: 2026-12-03 (7일)
- 한 문장: **주식 차트가 곧 지형이다. 개미가 차트 위를 달린다 — 급등은 벽, 상장폐지는 구멍. 레버리지는 점점 오르고, 언제 '익절'할지는 내가 정한다.**
- 유형: 하이 콘셉트 + 엄청난 중독성
- 참고 장르·메커닉: 끝없는 러너(탭 점프), '그만두고 챙길까 더 갈까' 위험 선택. 원작 게임의 그림·이름은 쓰지 않는다
- 표기: **가상 차트 · 투자와 무관** (실제 종목·실제 돈·투자 권유처럼 보이지 않게)

## 10초 안에 이해되는 핵심 행동
- 화면 탭 = 점프 (공중에서 한 번 더 = 2단 점프)
- 💰 익절 버튼 = 지금까지 수익을 확정하고 판 종료

## 한 판의 흐름 (20초~2분)
1. 개미가 캔들 차트 위를 자동으로 달린다. 8초마다 레버리지 +1(x1→x10): 빨라지고 수익도 커진다
2. 지형: 작은 계단은 그냥 넘고, **급등 벽**은 점프, **폭락**은 떨어져도 되지만 **상장폐지 구멍**에 빠지면 강제 청산
3. 공중의 📈 호재는 먹으면 보너스, 📉 악재는 피하기
4. 💰 익절하면 이번 판 수익률이 계좌에 더해진다. 청산되면 이번 판 수익은 0, 원금 10% 수수료

## 보상과 성장
- **한 판 보상**: 수익률 %가 계속 오르는 게 보인다(초록 숫자). 익절 순간 동전 비·꽃가루·'익절!' 연출
- **다음 판 이유**: "아까 x6에서 익절했으면…" — 최고 수익률·최고 레버리지 기록 갱신
- **긴 성장**: 계좌 잔고가 판을 넘어 쌓이고 칭호가 오른다 (개미 → 동학개미 → 슈퍼개미 → 큰손 → 고래). 잔고가 바닥나면 '재기 지원금' 10만원
- **곡선**: 레버리지 x1 속도 200 → x10 속도 400. 벽 높이·구멍 폭은 속도에 맞춰 늘되, 2단 점프로 항상 넘을 수 있게 생성(자체 검사로 확인)

## 손맛
- 착지 먼지(떨어진 높이만큼), 큰 낙하 착지 시 화면 흔들림, 착지 찌그러짐
- 레버리지 상승: 화면 테두리 번쩍 + 상승음 + 'x4!' 팝업
- 호재: 반짝이 + 피치가 올라가는 '띵', 악재: 붉은 번쩍 + 둔탁음
- 청산: 0.25초 멈춤 → 슬로 모션 → 붉은 번쩍 + 흔들림 + '강제 청산' 도장

## 이번 프로토에서 하지 않는 것
- 상점·아이템 구매, 캐릭터 꾸미기, 실제 시세 연동, 랭킹 서버, 튜토리얼 화면

## 판정
- 계속할 신호: 5명 중 3명 이상이 시키지 않았는데 3판 이상, 또는 중앙값 10분 이상
- 그만둘 신호: 5명 중 1명 이하 재플레이, 또는 익절 버튼을 아무도 쓰지 않음(위험 선택이 재미가 안 됨)

## 자동 검사
- `?selftest`: 시드 1~20 각각 봇이 60초를 청산 없이 달리면 통과 → 생성된 지형이 항상 넘을 수 있는지 확인
- `?autoplay=N`: 시드 N으로 봇 플레이(녹화용)
