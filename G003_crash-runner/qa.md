### 상점 가격과 계좌 곡선

계좌 = 이전 계좌 × (1 + 이번 판 수익률). 상점은 이 계좌에서 돈을 뺀다. 단계마다 한 번 통과(사람 근사 봇 값) 모형:

| 익절 방식 | 단계당 청산 | 안 삼: 1→6단계 뒤 계좌 | 살 수 있으면 바로 삼: 6단계 뒤 계좌 · 산 강화 |
|---|---|---|---|
| ★1 넘자마자 | 0 | 1.5M → 2.9M → 6.6M → 19M → 70M → **320M** | 2.0M · 2개(9레벨 중) |
| ★1 넘자마자 | 2 | 1.2M → … → 90M | 1.1M · 3개 |
| 깃발+10초 | 0 | 2.0M → 4.8M → 15M → 58M → 260M → **1,526M** | 0.8M · 5개 |
| 깃발+10초 | 2 | 1.6M → … → 431M | 9.2M · 4개 |

- **사면 성장이 멈춘다**: 1단계 통과(2,000,000P) 뒤 💪 버팀 근육(2,000,000P)을 사면 계좌 **0P** → 2단계를 +150%로 통과해도 0×2.5 = 0이라 바닥값 **100,000P**, 결과 화면 "변화 +100,000P"(`p_result_s2_after_buy.png`). 수익률이 계좌 크기에 곱해지는 구조라 산 만큼 앞으로 버는 돈도 같이 줄어든다
- 반대로 안 사고 모으면 금방 넘친다: 6단계까지 안 사면 90M~1.5B로 대부분을 한 번에 산다. 1단계(+96%)만 9판 반복하면 상점 전체(2.49억P)를 산다
- 결과: "살 수 있을 때 사면 손해, 끝까지 참았다 몰아 사면 이득"이라 상점이 '다음 판 이유'가 되기 어렵다(고칠 2)
- 🛡️ 손절매 계좌 Lv1(3,000,000P)은 4단계부터(큰손·고래) 효과가 없다. 몸이 이미 1회를 기본으로 주고, 둘은 겹치지 않는다(`buffs.stop = 9999` 한 번). 4단계의 새 아이템 🛡️ 손절매도 기본 1회를 쓰기 전에는 먹어도 아무 일이 없다(고칠 5)

### 익절 고민: 아이템이 없애 버리는가

- 없애지 않는다. 손절매(큰손부터 1회 기본)는 청산 1번을 막지만 수익 절반을 가져가서, 버티다 한 번 실수하면 ★이 날아간다(P40 6단계 0.87회/판 구조, 그 때문에 통과율 77%). 상한가·물타기·FOMC는 4~5초짜리라 "효과 끝날 때까지 버티고 익절"이라는 작은 고민을 오히려 더한다. 서킷브레이커는 3초 동안 느려질 뿐이다
- 고래(6단계·무한)는 곰·세력·찌라시를 모두 날려 버려서 몹이 보너스로만 남는다. 익절 고민은 이제 지형(높은 벽)에서만 나온다. 고민 자체는 남지만 6단계의 몹 다양성은 사라진다(디자이너 판단 사항)
- 실제 고민이 생기는 곳은 **x8 이후의 벽**이다. 고칠 2(시야)를 고치더라도 "x8 넘으면 위험해진다"는 감각은 남도록, 시야는 반응 0.25~0.4초로 지나갈 수 있을 만큼만 넓힐 것

### 첫 판 글 부담 (도감이 빈 첫 방문, 휴대폰 시야 기준 재현)

- 1단계 첫 20초 동안 카드 **7장**: 단계 안내 → (상장폐지·호재악재·곰 순서는 시드마다 다름) → 레버리지 → 상한가 → 세력. 카드 한 장이 2.8초씩 쉬지 않고 이어져, 20초 내내 화면 위에 카드가 떠 있다
- 대기열 때문에 카드가 **늦게** 뜬다. 만난 뒤 최대 3~7.6초 뒤에야 나오고, 🚀 상한가 카드는 4초짜리 효과가 끝난 뒤에 뜨는 경우가 많다(시드 1·2·3·5에서 +5~7.6초). 곰 카드가 곰을 지나간 뒤에 뜨기도 한다
- 2단계부터는 3~5초 간격으로 5~8장이 나오지만 새 용어는 2~3개뿐이라 견딜 만하다
- 새 규칙 등장 수: 1단계 6개(기본 용어 포함), 2단계 2개, 3단계 3개, 4단계 3개, 5단계 2개, 6단계 0개. 첫 단계에 가장 많이 몰려 있다
