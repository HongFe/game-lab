# G006 맛집 새치기 — 기획

- 단계: 프로토 · 시작: 2026-11-26 · 기한: 2026-12-03 (7일)
- 한 문장: **줄 선 지 3시간째, 그릇은 얼마 안 남았다. 앞사람이 안 볼 때만 살금살금 한 칸씩 앞으로.**
- 유형: 하이 콘셉트 + 웃긴 샌드박스 (잠입 타이밍)
- 참고 장르·메커닉: '안 볼 때만 움직이기' 잠입 타이밍. 원작 게임의 그림·이름은 쓰지 않는다

## 10초 안에 이해되는 핵심 행동
- **누르고 있으면** 앞사람을 살금살금 지나간다(진행 막대). 손을 떼면 멈춤(진행은 유지)
- 앞사람들 머리 위에 **❗**가 뜨면 곧 뒤돌아본다 → 손 떼기. 돌아볼 때 움직이고 있으면 들킨다

## 한 판의 흐름 (30초~90초)
1. 맨 앞 사람이 몇 초마다 가게로 들어가고 그릇이 하나씩 줄어든다
2. 그릇이 다 떨어지기 전에 내가 들어가야 한다 → 그냥 기다리면 못 먹는 줄 길이
3. 들키면 "새치기 하지 마세요!" → 두 칸 뒤로 + 경고 1개. 경고 3개면 쫓겨남
4. 성공: 가게 문이 열리고 음식 등장 · 별 = 경고 수 (0개 ★3)

## 보상과 성장
- **한 판 보상**: 아슬아슬하게 멈췄을 때 '휴…' + 심장 소리, 성공 시 음식 공개 연출(가게마다 다른 메뉴)
- **다음 판 이유** (2026-11-26 2차): 다음 가게 해금 + 메뉴·기믹 미리보기, 별 3개, 가게별 🏅 도전 과제 1개, 점수(콤보 가산)·최고 점수, 📖 맛집 도감(먹은 메뉴 모으기), 📅 오늘의 맛집(날짜로 고른 가게, 깨면 도장·연속 일수)
- **긴 성장(후보)**: 도감 보상(도감 다 모으면 특별 메뉴), 아이템 해금 순서, 오늘의 맛집 연속 보상
- **곡선** (2026-11-26 2차 재조정, 아이템·기믹 포함): 난이도는 눈에 보이는 것에서만 나온다 — 손님 구성, ❗ 예고 길이(가게별 배수 0.5~1), **두 번 보기**(`?` 0.5~1초 → 0.2초 ❗, 2번 가게부터 50%→80%), 사장님 감시(❗ 1초 예고). 목표(시드 200, 아이템 쓰는 봇): 반응 0.25초 봇 95%→40%, 0.4초 봇 85%→20%, 각 ±10%p · 역전 없음. 현재 0.25초: 100·92.5·83.5·79·72.5·67·62.5·57.5·49.5·47 / 0.4초: 92·78·72·61.5·58·50·42.5·33.5·28.5·23. 아이템 없을 때(0.25초): 100·85·71.5·65.5·54·60·48·35.5·21.5·30 → 아이템 효과 최대 +28%p(상한 30)

## 손맛
- 살금살금: 몸 낮추기 + 발소리 + 진행 막대, 지나갈 때 '쓱'
- ❗: 팝 효과 + 짧은 경고음, 돌아볼 때 얼굴 바뀜(뒤통수 → 째려봄)
- 들킴: 화면 흔들림 + 말풍선 + 뒤로 밀려남
- 아슬아슬: 들키기 0.3초 전에 멈추면 '휴…' + 심장 소리
