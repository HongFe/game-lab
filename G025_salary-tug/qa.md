읽은 것:
- **통과는 너무 쉽다.** 노랑만 쓰고 깃발에 바로 찍는 봇도 1~5단계 92~100%. 도전은 전부 ★에 몰려 있다
- **★3은 반응 속도 시험에 가깝다.** 반응 0.4초 → 0.7초로 늦추면 1단계 ★3이 42% → 0%, 5단계 통과가 93% → 82%. 빌더 표의 ★3 15~38%는 0.4초(빠른 사람) 기준이라, 실제 사람은 이보다 많이 낮을 것
- **역전 2곳**: 6단계 통과(95%)가 5단계(93%)와 같거나 높고, 깃발 도달도 28초 → 20초로 빨라짐. 2단계 깃발(19초)이 1단계(26초)보다 빠름
- **4·5단계 기준이 똑같음**(+29/34/39). 5단계만 어려워지고 보상 숫자는 그대로
- 첫 성공: 1단계 깃발 중앙 26초. 다만 첫 판에 계속 누르면 6초에 끊기고, **평판 −1로 다음 판 줄이 100 → 90으로 시작**(확인함). 처음 온 사람이 두 번째 판을 더 불리하게 시작한다
- 새 규칙은 단계마다 하나씩(헛기침 → 턱 괴기+성과급 → 시계+오퍼 → 전화+기분+맞받기 → 책상 치기+구조조정). 4단계는 반응 1 + 사건 1 + 몸 능력 1로 셋이 한꺼번에 나옴
- 카드 영향이 크다: 카드 없이 하면 1·3단계 ★3 0%. 커피 시점이 실제 판단거리라 좋음
- 보상 이어짐: 결과 화면의 다음 단계 미리보기·새 카드·"다음 별 +34%" 한 줄 모두 있음. 부장 ★3(7,200×1.39) = 1억 돌파 연출 맞음

### 고칠 목록 (우선순위 순)

1. **[높음·재미] 끝까지 짜내기가 공짜다 → 멈춤에 진짜 위험을 넣기.** 줄 0~30 구간에 들어가면 위험이 커져야 G003처럼 "여기서 찍을까"가 생긴다. 예: (a) 줄이 낮을수록 상대 예고가 짧아지거나 버럭이 잦아짐, (b) 초록에 오래 있어도 상대가 되당겨 줄이 조금씩 닳음(지금 초록은 줄 0 소모라 안전지대), (c) 같은 상대의 버럭 피해가 판 안에서 횟수마다 커짐. 확인 지표: ★3 노리기 봇의 '줄 30에서 멈춤'과 '줄 3에서 멈춤'의 기대값이 비슷해지고 끊김은 2배 이상 차이
2. **[높음·재미] ★ 기준을 반응 0.4초가 아니라 0.6~0.7초 봇으로 맞추기.** 지금은 반응이 조금 늦으면 ★3이 0%로 떨어져 '반응 속도 시험'이 된다(G013 위험). 예고 시간을 0.2~0.3초 늘리거나 버럭 피해를 '예고 동안 평균 장력'으로 계산해 판단(뗄지 말지)을 재고 속도는 덜 재기
3. **[중간] 첫 방문 평판 벌칙 없애기.** 1단계(또는 첫 3판)는 끊겨도 평판 −1을 주지 않기. 지금은 처음 온 사람이 7초 만에 끊긴 뒤 줄 90으로 다시 시작한다. 결과 화면 한 줄을 "빨강 오래 → 줄 끊김"처럼 원인이 보이게(아이콘 + 짧게), 책상 위 줄 막대에 아이콘 하나
4. **[중간] 맞받아치기 보상 키우기(직급 DNA).** 4·5단계에서 맞받기 이득이 +1.2~1.4%p라 체감이 안 된다. 브리프 값(과장 +3% + 피해 절반, 부장 +5% 피해 0, 임원 +8%)에 가깝게, 또는 성공 때 2초 기회를 과장부터 주기. 지표: 맞받기 vs 놓기 평균 인상 차이 4%p 이상
5. **[중간] 곡선 정리.** 통과가 거의 공짜(생존 봇 92~100%)이니 목표(깃발)를 1~5단계 2~4%p 올리고, 6단계는 5단계보다 어렵게(통과 역전·깃발 20초 역전 해소). 4·5단계 목표·★ 기준이 같은 것도 5단계를 조금 올리기. 1단계는 자동 도장보다 직접 도장이 이득이 되도록(시간 끝 자동 도장은 ★ 하나 깎기 등)
6. [낮음] 판 중·카드 고르기 화면 글자 크기 4단계 → 3단계(12px 카드 이름을 14로, 또는 30px 연봉 외 크기 정리). 브리프의 '글자 14px 이상'도 이걸로 맞음
7. [낮음] 캔버스 사건 띠 앞머리 이모지(💰·📨·☀️·⛈️·📉·🚩·🚪)를 아이콘 그림으로 바꾸거나 빼기
8. [낮음] 떠오르는 숫자가 같은 자리에 2~3개 겹침(턱 괴기 ×3 + 연봉 팝업). 기회 중에는 연봉 팝업을 하나로 합치기
