### 고칠 목록 (심각도 순)

1. **[버그·권장] 곰 체력 NaN → 무적.** 392행 `T.heal * 0 + ` 제거(또는 `|| 0`). 82% 런에서 생긴다. 고쳐도 곡선은 거의 그대로이므로 고친 뒤 `?selftest` 24/24만 확인하면 된다
2. **[버그·권장] `over` 중복 → 오락실 실패 2번 집계.** 배출구 처리에서 `if (run.lives <= 0 && !run.over)`로 한 번만 내보낸다. 플레이테스트 판정 숫자(실패 수)에 들어가는 값이다
3. **곰이 입구에서 붙잡아 웨이브가 1~3분 늘어짐.** 다음 중 하나를 권한다: ① 붙잡을 적은 다른 인형 사거리 안에 있을 때만, ② 붙잡기 최대 4~5초 후 놓아 주고 쿨다운, ③ 길의 앞쪽(입구에서 일정 거리 이내)은 붙잡지 않기. 자체 검사의 '일반 웨이브 평균 50초 이하'에 '최장 90초 이하' 같은 기준을 더하면 다시 생기지 않는다
4. **필살기 컷인 띠 줄이기.** 큰 띠는 종류별 첫 발동이나 영웅 이상만, 나머지는 인형 머리 위 작은 아이콘+이름 0.5초로 바꾼다. 사용자 규칙 '동시에 팝업 1개'에 해당한다
5. **인형 패널 위치.** 패널이 시너지 칩·릴 아래쪽, 바꾸기 줄을 펼치면 당첨 줄까지 덮는다. 패널을 필드 쪽(선택한 인형 근처, 캔버스 y<322)에 띄우거나, 뽑기를 누르면(스핀 시작) 패널을 자동으로 닫는다
