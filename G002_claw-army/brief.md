# G002 인형뽑기 군단 — 기획

- 단계: 프로토 · 시작: 2026-11-26 · 기한: 2026-12-03 (7일)
- 한 문장: **뽑기 릴을 탭으로 멈춰 인형을 소환하고, 같은 인형을 합성해 등급을 올려 몰려오는 먼지 군단에게서 배출구를 지킨다.**
- 유형: 엄청난 중독성 + 웃긴 샌드박스
- 참고 장르·메커닉: 슬롯(릴·니어미스·잭팟) × 랜덤 소환 디펜스(칸 배치·합체·웨이브) × 뽑기 타이밍 손맛. 특정 게임의 이름·그림·유닛은 쓰지 않는다
- 개편 이력: v1 집게 1회 뽑기 + 턴제 자동전투 → v2 전투 무대 연출(컷인·BGM·필살기) → **v3 (2026-11-26 사용자 피드백 "캐릭터 싸움이 다이나믹하고 특성이 보여야 함, 뽑기 자체가 부족, 슬롯 디펜스 느낌")**: 실시간 디펜스 + 슬롯 뽑기로 구조 변경. v2의 연출(컷인·BGM·히트스톱·필살기·인형 카드)은 재사용
- 반영 자료: `research/2026-11-26_유즈맵_장르_조사.md` 2·4장(랜덤 디펜스: 확률 공개·등급 5단계·합성·확정 레시피·미션·보스 보상 고르기·판매·바꾸기 도박·배속). 사용자 규칙(2026-11-26) "글씨·정보는 심플하게" 적용

## 10초 안에 이해되는 핵심 행동
- **🎰 뽑기**(또는 기계 화면 탭) → 릴 3개가 돈다 → **탭할 때마다 하나씩 멈춤**(가운데 줄에 원하는 그림이 올 때)
- 결과 인형을 집게가 집어 칸에 내려놓는다 → 인형은 알아서 싸운다. 적이 배출구에 닿으면 ❤️가 준다

## 한 판(런)의 흐름
1. 준비 6초(시작 코인 30) → 웨이브 시작. 적은 왼쪽 위 입구 → 위 → 오른쪽 → 아래 → 왼쪽 배출구로 칸 주위를 한 바퀴 돈다
2. 뽑기는 전투 중에도 계속(적이 다가오는 동안 릴을 멈춰야 하는 긴장). 비용 10코인부터, 뽑을 때마다 +1
3. 릴 결과
   - 같은 인형 3개 **잭팟**: 희귀(2등급) 소환 + 5코인, 화면 번쩍·코인 분수·팡파르
   - 2개 **페어**: 일반 소환 + 4코인
   - 모두 다름: 가운데 그림 일반 소환 / 가운데가 💨면 **꽝**(+4코인)
   - 💨 3개 '먼지 잭팟': +20코인
   - **니어미스**: 앞 두 릴이 같으면 셋째 릴이 느려지고 빨갛게 두근거림, 빗나가면 '아깝다!'
4. 칸은 8개. 칸이 가득 차면 뽑기 버튼이 '칸 가득'으로 바뀐다 → 인형을 눌러 패널에서 정리
5. **인형 패널**(인형 탭, 아이콘+숫자 버튼 4개)
   - ⬆ **합성**: 같은 종류·같은 등급 2개 → 한 단계 위. 70% 같은 종류, 30% 무작위 종류(🎲 두근)
   - 📜 **레시피**(운 완충, 확정): 같은 등급 서로 다른 3종 → 고른 인형 종류로 한 단계 위 100%
   - 💱 **바꾸기**(도박): 15코인, 60%로 원하는 종류로(등급 유지)
   - 💰 **판매**: 일반 5 · 희귀 12 · 영웅 30 · 전설 70 (신화 판매 불가)
6. **등급 5단계**: 일반·희귀·영웅·전설·신화 (색 테두리 + 첫 글자). 힘 배수는 한 단계마다 ×2.2 → 합성이 항상 이득(장르의 '합치면 약해짐' 불만을 피함)
7. **보스 보상 3개 중 1개 고르기**(5웨이브마다): 영웅 인형 / 코인 +40+10w / 뽑기권 3 / 목숨 +3 / 전원 공격 +15%(계속) 중 무작위 3개. 고르는 동안 게임 정지
8. **미션 5개 + 히든 2개**(🎯 버튼에 접어 둠, 완료 시 한 줄 알림): 6종 모으기 40🪙 · 영웅 만들기 🎟️2 · 시너지 2개 25🪙 · 잭팟 3번 🎟️1 · 전설 만들기 80🪙 / 히든: 💨💨💨 먼지 잭팟 🎟️3 · 곰 3마리 50🪙. 뽑기권 🎟️ = 공짜 뽑기
9. **확률표 공개**(📊 버튼): 릴 한 칸 확률(곰 18.8%, 나머지 5종 각 12.5%, 💨 18.8%), 아무 때나 멈출 때 잭팟 1.6%, 합성 70%, 레시피 100%, 바꾸기 60%, 판매가
10. 적 처치 1코인(보스 15), 웨이브 클리어 보너스 5+웨이브
11. ❤️ 10개(필드 위 하트 줄 + 🚪-n 새어 나간 수), 일반 적이 새면 -1. **보스(5웨이브마다, 고무 오리)가 배출구에 닿으면 즉시 패배**. 0이 되면 런 종료 → 최고 웨이브 기록
12. 배속 버튼 ▶1 / ▶2 / ▶3

## 손맛·연출
- 슬롯: 레버 당김, 릴 회전 틱 소리·잔상, 릴 멈춤 '딱'(릴마다 음 높이 다름)+튕김, 다음 멈출 릴 노란 테두리 '탭!', 니어미스 두근, 잭팟 전구 전체 금색 깜빡임·코인 분수·팡파르·히트스톱, 당첨 그림 금색 원
- 소환: 집게가 릴에서 인형을 집어 칸으로 포물선 비행 → 착지 고리·반짝이, 소환 직후 사거리 원 2초 표시
- 전투(실시간): 고양이 돌진·복귀, 곰 몸통 들이밀기+할퀴기 궤적+🛡️·도발 줄, 토끼 점프+당근, 공룡 불덩이 꼬리 불꽃+폭발 고리, 문어 먹물탄+보라 웅덩이, 펭귄 눈덩이+오라 고리, 피격 번쩍·넉백(길 뒤로 밀림)·데미지 숫자(크기 ∝ √피해), 기절 별, 감속 보라 표시
- 필살기: v2 컷인 띠 + 종류별 효과(지진 균열·브레스 불꽃 분사·할퀴기 자국·분신·오로라·먹물 어둠), 무대 조명 색이 필살기 색으로
- 웨이브 시작 배너, 보스 웨이브 WARNING 띠 + 고무 오리 + 하단 보스 체력바(흰 잔상), 보스 격파 슬로모션 0.25배 1.1초 + '보스 격파!'
- 배출구에 새면 붉은 번쩍·흔들림·❤️-1. 무대 조명: 보통 보라, 보스 빨강 깜빡임
- BGM: Web Audio 리듬 루프, 적이 배출구에 가까울수록·많을수록 악기가 쌓임, 보스 웨이브는 빠른 긴장 진행. 🔊(또는 M키) 끄기, 저장
- `?nojuice`: 흔들림·슬로모션·히트스톱·번쩍임·파티클 끔. 데미지 숫자·팝업은 남김
