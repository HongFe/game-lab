# G011 출근길 피하기 — 기획

- 단계: 프로토 · 시작: 2026-11-26 · 기한: 2026-12-03 (7일)
- 한 문장: **환승통로에 쏟아지는 백팩·우산·킥보드를 손가락 하나로 피해 9시 전에 사무실 도착.**
- 유형: 엄청난 중독성 + 하이 콘셉트
- 참고 장르·메커닉: 커스텀 맵 '피하기(탄막 회피)' 장르. 원작 이름·그림은 쓰지 않는다

## 10초 안에 이해되는 핵심 행동
- 화면 어디든 **끌면** 내 캐릭터가 손가락을 따라 움직인다(손가락에 가리지 않게 살짝 위)
- 부딪히면 셔츠에 커피 얼룩(목숨 3개). 시계가 9:00이 되면 도착

## 한 판의 흐름 (40~60초)
1. 8:59:00부터 시작, 60초 버티면 9:00 정각 출근
2. 낱개 장애물: 백팩 멘 사람(가방을 돌려 휘두름), 우산(주기적으로 펼쳐져 커짐), 킥보드(경고 줄 뒤 빠른 직선), 전단지 아주머니(천천히 따라옴)
3. 대형(2026-11-26 추가, 노선마다 4~8초 간격. 직전 대형의 맨 윗줄이 새 줄보다 max(150px, 속도×1.4초) 아래로 내려온 뒤에만 다음 대형 → 겹쳐서 통과 불가인 벽 없음): 인파 벽(틈 1개) · 지그재그(반쪽 벽이 좌우 번갈아 3~4줄) · 양쪽 협공(화면 위·옆 통로에서 인파가 몰려와 틈 하나만 남음) · 백팩 회오리(6개가 고리로 돌며 나를 살짝 따라옴) · 에스컬레이터(좁은 레인 안으로 들어가야 함, 밖이면 얼룩+밀려남, 안에 서 있는 사람 지그재그. 레인 접근 중엔 레인 밖으로 킥보드, 레인 윗변이 나를 지나면 장애물 다시 출현) · 계단(띠 안에서 내 속도 0.55배)
4. 9시에 가까울수록 빨라짐: 장애물 속도 시작 1.0배 → 끝 1.6배(곡선), 출현 간격도 줄어듦. 마지막 15초는 '9시 임박' 연출
5. 커피를 먹으면 2초 무적 대시
6. 노선(레벨) 5개: 2호선 → 9호선 급행 → 신도림 환승 → 강남역 → 월요일 아침

## 조작·판정 (2026-11-26 난도 개선)
- 내 최대 속도 290px/s(이전 480), 대시 460. 손가락 추종 세기 13, 관성: 목표 속도로 따라붙는 비율 11/초(살짝 미끄러짐)
- 충돌은 그림과 같은 모양: 사람·우산 = 원, 백팩 멘 사람 = 몸 원 + 가방 원(둘 중 하나만 닿아도 얼룩 — 이전엔 둘 다 닿아야 맞던 버그), 킥보드 = 세로 캡슐, 에스컬레이터 = 레인 벽. `?hitbox`로 판정선 표시
- 그림: 이모지 대신 캔버스 도형(사람 실루엣·가방·우산·킥보드·커피컵), 통로 배경(흘러가는 바닥 타일·점자 블록·벽 광고판·노선 색 띠·역 표지판)

## 보상과 성장
- **한 판 보상**: 아슬아슬하게 스치면 '휙!' 슬로 모션 + 점수, 도착 순간 회사 문 + '9:00 출근' 도장
- **다음 판 이유**: 무피해(얼룩 0) 도전, 아슬아슬 횟수 기록, 다음 노선 해금
- **긴 성장(후보)**: 무한 모드(지각까지 몇 초 버티나), 출근 복장 해금
- **곡선**: 노선마다 장애물 밀도·속도·종류 증가. 자체 검사로 회피 봇이 노선마다 대부분 도착하는지 확인(틈이 없는 패턴 금지)

## 손맛
- 스침(아슬아슬): 화면 살짝 느려짐 + '휙' + 노란 테두리
- 부딪힘: 커피 튀김 파티클 + 흔들림 + 붉은 가장자리, 0.8초 깜빡이 무적
- ☕ 대시: 무지개 잔상
- 9시 가까워지면 시계 째깍 소리가 빨라짐
