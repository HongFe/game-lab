# 유즈맵 장르 조사 — game-lab 설계용 (2026-11-26)

- 목적: 스타·워크 유즈맵 장르가 왜 '한 판 더'를 만들었는지 정리하고, 진행 중인 프로토(G002·G011·G012, 참고 G003·G006)에 가져올 장치를 고른다
- 범위: **메커닉만**. 원작 맵 이름·유닛·그림은 가져오지 않는다(CLAUDE.md 절대 규칙)
- 표기: **[출처]** = 아래 출처에서 확인한 사실 / **[분석]** = 출처를 바탕으로 한 설계 판단(검증된 사실 아님)
- 한계: 공개 웹 자료가 얕다. 나무위키 장르 문서 3개가 핵심 근거이고, 강화하기·피하기 개별 맵의 수치는 확인하지 못했다. 시장성(수익·경쟁작)은 business 영역이라 다루지 않는다

## 1. 장르 지도 [출처: 나무위키 「스타크래프트/유즈맵」]

| 장르 | 승리·실패 | 반복을 부르는 장치 | 우리 프로토 |
|---|---|---|---|
| 피하기/바운드 | 닿으면 죽음. 끝 지점 도달 또는 시간 생존 | 스테이지마다 패턴 변화, 리듬형은 음악에 맞춘 패턴 암기 | G011 출근길 피하기 |

## 2. 랜덤 디펜스 — 두 표본의 숫자

### 2-1. 랜덤 타워 디펜스(랜타디) [출처: 나무위키 「랜덤 타워 디펜스」]
- 등급 5단계(노멀·매직·레어·유니크·에픽) × 티어당 8종 = 40종
- **조합: 같은 티어의 같은 타워 2개 → 상위 티어 1개(랜덤)**. 매각은 티어 비례, 최고 티어는 매각 불가
- 업그레이드 자원(가스)은 10~120 **랜덤 지급**
- **미션**: 기본 미션(예: 노멀 8종 모두 보유 → 300, 레어 7개 → 300) + **히든 미션**(정해진 8개 조합 → 상위 시민 보상). 미션이 '무엇을 모을지' 목표를 준다
- 40라운드, **10·20·30 보스 + 40 최종 보스**. 보스 처치 시 자원 + **상위 유닛을 골라 받는 보상**
- 킬 수 업적(333·666·999·1333)이 라운드 진행과 맞물려 중간 목표가 된다
- 인기 이유: 랜덤이라 경우의 수가 무한, 운과 실력이 모두 필요. 방송인 플레이로 확산

### 2-2. 메이플 운빨 디펜스 [출처: 나무위키 「메이플 운빨 디펜스」]
- 시작 25, 소환 1회 10. 처치로 2차 자원 → 환전
- 유닛 3계열(소형 특화·대형 특화·만능) = 상성
- **등급 9단계와 확률(초기 표)**: 일반 50% · 레어 33.1% · 고대 10.2% · 유물 5.1% · 서사 0.8% · 전설 0.5% · 에픽 0.2% · 신화 0.08% · 태초 0.019%. 상위 등급은 판매 불가
- **도박(교환)**: 전설 100 → 66%로 다른 전설, 신화 250 → 50%로 다른 신화. 원하는 유닛을 콕 집어야 해서 체감 성공률은 약 절반
- 보스: 큰 자원 + 유물·서사·전설 중 **골라 받기**, 일부는 20%로 상위 등급
- 라운드 2분 20초(보스 5분 20초), 95라운드부터 시간 안에 못 지우면 패배. 2·4·6배속
- 확산: 2022년 10월 방송으로 급확산 — **배우기 쉬움**이 주요인
- 비판: 확률 조작·클리어 차단 의혹(문서상 확인됨으로 기술), 운 비중이 너무 높고 난이도가 가혹 → 치트·변조판으로 이탈
- 참고(다른 자작판): 운이 없어도 재료만 모으면 **확정으로 나오는 특수 조합 5종**을 둬서 운과 확정 경로를 함께 제공 [출처: 검색 요약]

### 2-3. 모바일 파생(랜덤 다이스 계열) [출처: 검색 요약, 스토어 설명·플레이어 의견]
- 같은 종류·같은 눈 2개 합치면 1단계 상승, **합친 결과의 종류는 랜덤**
- 플레이어 불만: 고레벨 합성 비용이 커서 합치면 오히려 약해짐 / 난이도 급등이 갑자기 옴

## 3. 장르별 '한 판 더' 장치 [분석]

**랜덤 디펜스**
1. 가벼운 진입: 소환 버튼 하나. 규칙 설명이 거의 필요 없다
2. 3단 보상 리듬: 매 소환(작은 두근) → 합성(중간 쾌감, 결과 랜덤) → 상위 등급 등장(큰 쾌감, 0.x% 희귀)
3. 목표를 주는 미션: '이 조합 모으기'가 랜덤에 방향을 준다. 히든 미션은 발견의 재미
4. 보스 = 체크포인트 + **골라 받는 보상**(운의 불만을 선택으로 상쇄)
5. 운 완충 장치: 확정 조합, 도박(교환)으로 원하는 것 노리기, 판매로 되돌리기
6. 실패 위험: 운 비중이 너무 높거나 확률이 불투명하면 이탈(운빨 디펜스 비판). → **확률 공개 + 확정 경로**가 필수

**피하기**
1. 즉시 이해: 닿으면 죽음
2. 패턴 = 레벨 디자인. 스테이지마다 '새 패턴 하나'를 배우는 구조
3. 암기 가능한 패턴 + 리듬(음악)이 숙련감을 만든다. 무작위 탄막만으로는 숙련감이 약하다
4. 짧은 구간 + 즉시 재시도가 반복을 부른다

**강화하기**
1. 결과가 즉시, 크게 보인다(성공/실패/파괴)
2. 확률이 가혹할수록 성공 순간의 쾌감이 커지지만, 무한 반복만 남으면 지루하다 → 강화 결과를 **쓸 곳**(보스·경쟁·판매)이 있어야 순환이 생긴다
3. 다인 경쟁(누가 먼저 +N)이 동기

## 4. 우리 프로토에 가져올 것 [분석 → 빌더 전달]

### G002 인형뽑기 군단 (랜덤 디펜스)
- 확률표를 화면에 공개하고 등급 5단계 정도로(9단계는 모바일 첫 판에 과함)
- **같은 인형 2~3개 → 상위 등급**, 합성 결과 종류 일부 랜덤(두근) + **확정 조합 레시피**(운 완충)
- **미션 3~5개**(예: 6종 모두 모으기, 같은 종류 ★3, 특정 2종 조합) → 보상 코인/뽑기권. 히든 미션 1~2개(발견용)
- 보스 라운드 보상은 **3개 중 골라 받기**
- 판매(되돌리기)와 '원하는 종류로 바꾸기' 도박(확률 공개)
- 배속 버튼, 라이프(새어 나간 적 수) 표시
- 피할 것: 숨은 확률, 클리어 불가 구간(이미 QA에서 R10 벽 경험)

### G011 출근길 피하기 (피하기 → 슈팅)
- 스테이지마다 **이름 붙은 새 패턴 1개**를 소개하고, 다음 스테이지에서 섞기
- 패턴을 **고정 시드(외울 수 있음) + 약간의 랜덤**으로. 같은 스테이지는 같은 패턴 뼈대
- BGM 박자에 패턴을 맞추면 숙련감(리듬형 피하기)
- 짧은 구간 + 즉시 재시작, 구간 시작점 체크포인트

### G012 집 강화하기 (강화하기 + 키우기)
- 강화 결과에 **쓸 곳** 만들기: 갈래 지도에서 '어디로 갈지' 선택, 사건(규제·폭락) 대응
- 실패 종류 다양화(그대로·하락·일시 정지·우회 경로), 확률 공개 유지
- 보스 = 시장 사건, 이기면 **골라 받는 보상**
- 확정 경로(예: 오래 기다리면 확정되는 재개발 입주)로 운 완충

### 참고: G003 폭락 러너 (키우기)
- 단계 클리어마다 '진화' 연출 + 다음 몸의 능력 미리보기(키우기 장르의 진화 동기)
- 킬 수 업적처럼 판 중간 목표(곰 N마리 밟기 등)

### 참고: G006 맛집 새치기
- 미션·업적(가게별 도전 과제)은 이미 반영. 히든 도전(발견형) 추가 여지
