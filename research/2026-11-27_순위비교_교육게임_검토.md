# 순위·비교 요소 검토 + 교육용 게임 기획안 (Command Center 지시 #72 · 2026-11-27)

- 범위: game-lab이 맡을 수 있는 1·2번만 다룬다
  - 1번: 지금 게임에 '상대방과 비교·순위'를 넣을 수 있는지
  - 2번: 교육용 게임 아이디어 1~2개 기획안
- 범위 밖이라 다른 곳으로 넘긴다
  - 수익 모델(순위 + 광고), 플랫폼화(큐레이션 → 사용자 아이디어 접수, 스팀 모델) → **business**에서 사업 검증
  - 허브 등록(`agents.json` 변경) → **command-center(Master)**. 등록할 파일은 이 문서
- 한 줄 결론
  - **순위는 지금 8개 게임 모두에 넣을 수 있다.** 게임들이 이미 레벨 결과(점수·별·단계)를 오락실로 보내고 있어서, 오락실 쪽에 표 하나와 화면 하나만 더하면 된다
  - 다만 **모든 사람끼리 비교하려면 공유 DB(Supabase)가 필요하다.** 외부 계정을 만드는 일이라 사용자 승인이 필요하다
  - 승인 전에는 '봇 기준 상위 N%'와 '결과 카드 공유'로 비교 느낌을 낼 수 있다

## 1. 순위·비교 요소 검토

### 1-1. 게임별로 무엇을 겨룰 수 있나

오락실로 이미 오는 신호를 기준으로 정리했다(`level_clear` 데이터, 2026-11-27 코드 기준).

|---|---|---|---|
| G003 폭락 러너 | 단계, 수익률(ret), 레버리지 | 단계별 최고 수익률 · 고래까지 걸린 판 수 | ◎ 수익률 숫자 자체가 비교 욕구를 만든다 |
| G013 지옥철 밀어넣기 | 역, 별, 점수, 탑승, 튀어나감 | 역별 최고 점수 · 무한 출근 도달 역 | ◎ |
| G011 출근길 피하기 | 노선, 점수, 콤보, 남은 목숨 | 노선별 최고 점수 · 무한 출근 버틴 시간 | ◎ 슈팅 장르는 점수판이 기본 |

| G004 고양이 타자수 | 레벨, 간식 수, 별 | 레벨별 최소 간식 | ○ 퍼즐형 |

### 1-2. 만드는 방법 세 가지

| 방식 | 비교 대상 | 필요한 것 | 정직성 | 추천 |
|---|---|---|---|---|
| A. 공유 순위표 | 모든 테스터 | Supabase 프로젝트 1개(무료 등급) — `arcade/feedback.sql`에 이미 구조가 있음. `scores` 표 하나 추가 | 진짜 순위 | **사용자 승인 후 1순위** |
| B. 봇 기준 상위 N% | 자체 검사 봇 수천 판의 분포 | 추가 계정 없음. 게임마다 이미 있는 사람 근사 봇 결과를 분포로 저장 | "봇 기준"이라고 반드시 표기 | 승인 전 임시 |
| C. 결과 카드 공유 | 친구(카톡) | 추가 계정 없음. 결과를 짧은 카드 문구로 복사·공유 | 진짜 비교(사람 대 사람) | A·B와 같이 |

**A 설계 요점** (승인이 나면 오락실에서 한 번 만들면 8개 게임에 모두 적용된다)
- 표 `scores(game_id, level, metric, value, anon_id, nick, version, created_at)`
- 테스터는 쓰기만 한다. 읽기는 게임·레벨별 상위 N개와 내 순위만 돌려주는 집계 뷰로 한다(행 수준 보안)
- 개인정보: 지금처럼 테스터 번호와 선택 닉네임만 쓴다. IP·이메일·실명은 받지 않는다
- 조작 대응: 브라우저에서 보낸 점수는 위조할 수 있다. 프로토 단계에서는 게임별 '봇 최고치 × 1.5' 같은 상한을 넘는 값을 버리는 정도로 충분하다. 상금·보상을 거는 순간부터는 서버 검증이 필요하다
- 화면: 결과 화면에 "🏆 이번 주 12위 / 87명", 오락실 목록에 게임별 1위 닉네임 한 줄. 화면 글은 한 줄 규칙을 지킨다
- 재방문 장치: 주간 초기화, 오늘의 도전(G006 '오늘의 맛집'과 같은 방식), 내 기록이 밀리면 다음 방문 때 "내 기록이 3칸 밀렸어요" 표시

### 1-3. 주의할 점 (설계 판단)
- **판정 숫자와 섞지 않는다.** game-lab의 유지/폐기 판정은 "시키지 않았는데 다시 했는가"다. 순위가 생기면 재플레이가 늘 수 있으니 순위를 켜기 전과 후를 나눠서 기록한다(`version`으로 구분)
- **운 비중이 큰 게임은 '최고 기록' 순위만 둔다**(G002). 평균 순위는 운 때문에 억울함을 만든다
- **아이 대상 게임은 공개 순위를 기본으로 끈다.** 2절 참고
- 광고 수익 구조(순위 화면 상단 광고 등)는 business에서 판단한다. 기술적으로는 오락실의 결과 화면이나 목록 상단 한 칸에 넣을 수 있다

### 1-4. 바로 할 수 있는 다음 단계
1. (승인 불필요) 결과 카드 공유(C)를 오락실에 추가한다 — 반나절
2. (승인 불필요) 게임별 '봇 기준 상위 N%'(B)를 결과 화면에 추가한다. 게임별 작업이라 각 빌더가 한 번씩 손대야 한다
3. (**사용자 승인 필요**) Supabase 프로젝트를 만들고 `scores` 표와 순위 화면을 추가한다(A) — 오락실 하루

## 2. 교육용 게임 기획안 (2개)

피드백: "단순 재미보다 '이게 나한테 도움 되네' 느낌", "아이들 지능 향상 계열"
- 참고: 피드백에 나온 '쥬차'가 어떤 게임인지 확인하지 못했다. 정확한 이름을 알려 주면 장르·메커닉만 참고해 다시 보겠다(원작 복제 금지 원칙)
- 공통 원칙
  - **도움이 눈에 보이게**: 판이 끝나면 "오늘 늘어난 것" 한 줄을 보여 준다. 예: "거스름돈 계산 8초 → 5초"
  - **난이도 자동 조절**: 맞히면 한 단계 위로, 두 번 틀리면 한 단계 아래로. 틀려도 놀리지 않는다
  - **아이 대상 보호**: 개인정보 0, 공개 순위 기본 끔(가족·친구끼리만), 광고는 보호자 화면에만, 하루 권장 시간 알림
  - 화면 글은 한 줄 규칙. 글을 못 읽는 아이를 위해 아이콘과 소리 위주로 만든다

### 2-1. 「동네 가게 거스름돈」 — 셈하기 + 돈 감각 (6~10세)
- 한 문장: **동네 가게 계산대에서 손님에게 거스름돈을 동전·지폐로 건넨다. 빨리, 그리고 적은 개수로.**
- 핵심 행동: 손님이 낸 돈과 물건값이 보이면 아래 동전·지폐를 끌어 거스름돈을 만든다. 맞으면 손님이 웃고 다음 손님이 온다
- 단계
  1. 10원 단위 덧셈 → 2. 받은 돈 − 물건값 → 3. 최소 개수로 주기(그리디 사고) → 4. 할인·묶음 가격 → 5. 손님 여러 명 줄서기(속도)
- 도움 보이기: 문제당 평균 시간, 최소 개수 성공률, 틀린 유형("받은 돈 빼기에서 받아내림")을 보호자 화면에 표시
- 재미 장치: 가게 꾸미기(맞힌 수로 진열대 해금), 단골손님 도감, 콤보
- 순위: 가족·친구 그룹 안에서만 '이번 주 계산 속도'
- 기존 자산 재사용: G006의 줄서기 손님 표현, G012의 돈 단위 표시
- 첫 점수(초안, game-designer 재검토 필요): 훅 3 · 클립 2 · 반복 4 · 범위 5 · 새로움 3 = **17점** → 그대로는 승격 기준(18점) 미달. 교육 축을 따로 평가할지 business와 정해야 한다

### 2-2. 「고양이 길 코딩」 — 순서·조건 사고력 (7~12세)
- 한 문장: **고양이에게 화살표 카드를 순서대로 줘서 간식까지 데려간다. 반복·조건 카드가 열리면 더 짧게.**
- 핵심 행동: 화살표 카드(↑ → ↓ ←)를 줄에 끼우고 ▶를 누르면 고양이가 그대로 움직인다. 틀리면 어디서 틀렸는지 발자국으로 보여 준다
- 단계
  1. 순서(카드 3~6장) → 2. 반복 카드 "🔁×3" → 3. 조건 카드 "🐟 보이면 →" → 4. 함수 카드(내 동작 묶음) → 5. 카드 수 제한 퍼즐
- 도움 보이기: "오늘 배운 것: 🔁 반복"처럼 개념 배지, 같은 길을 더 적은 카드로 푼 기록
- 재미 장치: 고양이가 엉뚱하게 움직이는 실패 장면(웃음), 최소 카드 별 3개, 고양이 옷 모으기
- 순위: 레벨별 최소 카드 수(퍼즐형이라 운 없음, 공정)
- 기존 자산 재사용: G004 고양이 타자수의 고양이 그림·키보드 맵 구조
- 첫 점수(초안): 훅 3 · 클립 3 · 반복 4 · 범위 4 · 새로움 3 = **17점**

### 2-3. 진행 제안
- 동시 진행이 8개로 한도가 꽉 차 있어서 **지금은 기획안까지만** 한다. 프로토를 만들려면 기존 프로토 하나를 폐기·보류하거나 한도를 올려야 한다
  - 후보: G001 이중주차 탈출·G004 고양이 타자수는 첫 버전 그대로이고 피드백이 없다
  - G004를 「고양이 길 코딩」으로 바꾸는 방법도 있다(같은 고양이 자산)
- 교육 게임은 지금 판정 기준("시키지 않았는데 다시 했는가", 성인 지인 5명)과 대상이 다르다. 아이 테스터와 보호자 동의 같은 테스트 방식은 사용자 결정이 필요하다
